# roughs（生徒のラフ画 ＝ デモ用の見本）

「継ぐ」で、生徒の手描きラフを職人の目安で確かめる流れを見せるための画像。

**これは本物の生徒の作品ではない。** デモのために、コード（Node のスクリプト）で線を少しずつ揺らして手描き風に描き、ヘッドレスのブラウザ（Playwright）で PNG にした。外の画像や作品は使っていない。氏名の欄はわざと空けてある。文字は IPA Pゴシック（IPA フォントライセンス）を 1 文字ずつ傾けて描いた。

## 共通の条件

- 石：淡い青のトリリアント（角の丸い三角）。長辺 8.88 mm、幅 7.52 mm、深さ 4.24 mm（上側 1.27 mm／下側 2.97 mm として描いた）。
- 指輪：一粒石、サイズ 11 号（内径 16.3 mm）。
- 図：上から見た図と、横から（指の方向から）見た図。縮尺は 4：1（1600 × 1200 px の紙を A4 横とみなす）。図の寸法は mm の値に合わせて描いてある。
- 紙：生成りの用紙、鉛筆の線、色鉛筆の青、消しゴムで消した跡と下書きの線つき。
