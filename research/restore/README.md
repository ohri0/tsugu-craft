# 途切れた技：例の記録

`sample.json` は、画面の「例を見る」で読み込む記録。合言葉のない人にも、案の見え方が分かるように置いた。

- **技も手がかりも試した結果も、すべて架空。** 「霜目の小箱」という技はない。手がかりの文には【架空】と書いた。写真は計算で描いた図で、図の中にも「架空の図」と書いた。
- **工程の案は、本物の Claude が実際に出したもの。手を加えていない。** 2026-11-05 に、画面から 1 つずつ手がかりを足して案 1 を作り、架空の結果を残して案 2 を作った。
- 画面では、文の中の【架空】の印と番号（C1・T1）を外し、「これは作り話の例です」の札を 1 つ出す。ファイルの中は変えない（書き換えたのは、例の印 `sample` と、技の名前から「（架空の技）」を外したことだけ）。
- 中身を書き換えない。作り直すときは、画面の「記録を書き出す」で出したファイルに置き換える。

## sample-moyou.json（雨垂れ銀・模様の見込みつき）

- 2026-11-07 に作った、もう 1 つの例。**技も手がかりも試した結果も、すべて架空。**「雨垂れ銀」という技はない。
