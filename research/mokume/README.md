# 木目金（もくめがね）の答え合わせ用の資料

伝統の技の作り方を、まわりの手がかりから組み立て直し、本当の作り方と照らし合わせる試し（ホールドアウト・テスト）に使う資料。最初の題材は木目金。

## ファイル

- `clues.md` — **手がかり**（C1〜C20）。残っている品物の見た目、断面に見える層、使われた金属と色、時代と土地、そのころの道具、一般に知られている物理の事実だけを書いた。技法の名前と、作り方の順番は書いていない。**仮説を立てる段に渡す。**
- `answer.md` — **答え**（工程 A1〜A11、今のやり方 M1〜M5、歴史 H1〜H9）。発表されている作り方と歴史。**答え合わせの段まで隠しておく。** 仮説を立てる段には読ませない。

どちらも 2026-11-02 のウェブ検索の要約にもとづく。原文を開けなかったところが多いので、確かめていないところは「未確認」と書いた。どの文にも出典の URL をつけた。

## 正直に書いておくこと

言語モデルは、学習のときに木目金の作り方をすでに読んでいるかもしれない。そうなると、手がかりから考えたのではなく、覚えていたことを出しているだけ、ということがありうる。

そこで答え合わせでは、作り方が合っているかだけでなく、**仮説の一つ一つの工程が、渡した手がかり（C の番号）を引いているか**も確かめる。手がかりを引かずに出てきた工程は「覚えていた可能性がある」として分けて数える。
