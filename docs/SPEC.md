## 中心の一回り（最初の画面）

1. **作る。**：石の写真から輪郭と尖った角を読み、立体の石にする。Claude が道具（set_setting / set_shank / check / look）で指輪を組み、帳面で確かめ、作れない所を直す。作業の記録を一行ずつ見せ、全部戻せる。合言葉がないときは、決まりごとから作った案を出す。
2. **整える。**：作れない所を 3D で赤く光らせ、今の値・必要な値・理由・根拠の決まり（職人の名前と言葉と日付、または公開情報）・見た目への影響つきの直し方を出す。人も同じつまみで直せる。
3. **渡す。**：指示書（何を作るか・確かめた結果・根拠の決まり）、原寸の型紙、3D データ（STL）。作り方の手順は書かない（職人が決める）。
4. **帳面**：職人が声で決まりを話すと、Claude が決まりの案にし、職人が承認すると帳面に入る。数字のある決まりは、その場で今の設計の確かめに効く。

## 最初の題材：一粒石の指輪（元の Stone Fit）

> 古い所が多い：3 案のカード・1 円玉で測る家での流れ・まとめて取り込む平たい石・PDF の指示書は作っていない。V 字の爪は選べないようにした。石の写真は「長辺と深さだけ測って入れる」。いまの画面は `docs/SCREENS.md`。

石の写真と、ノギスまたは 1 円玉だけで、その石に合う一粒リングを 3 案出し、職人がそのまま作れる原寸の型紙と指示書にする。以下の「全体の流れ」から「精度の証明」までは、この題材の詳しい仕様。

## 全体の流れ

家では 1 円玉で案を決め、お店では石を外してノギスで精密に合わせる――現場の流れそのままの 2 段構え。

```
家で（お客さま）   1. 指輪を撮る（1円玉と一緒に） → 2. 3案が出る（おおよその値段も） → 3. 案を持って来店
                                                                                      ↓
お店で（職人）     4. 石を外して測る（ノギスと写真） → 5. 型紙と指示書（Claude が組み、確かめて直す） → 6. 職人が作る
お店だけで始めるときは 4 から。平たい石は何石でもまとめて 4〜6 を通せる。
```

家での案は「見て決めるため」の精度（0.数 mm）で、作るための寸法はお店で測り直す。

## 画面と操作

画面は 2 つに分ける。PC は左に手順の窓、右に大きな 3D。スマホは上半分に 3D を固定し、下の手順をスクロールする。

1. **石の数**：1 石 / まとめて（平たい石）
2. **写真**：撮る・選ぶ。全体の写真と、石の拡大を並べ、取った輪郭を緑の線で重ねる。違う所を拾ったら、石を押して選び直す
3. **大きさ**：長辺と深さ（ノギス）。幅は空欄なら写真から出す。家では 1 円玉か定規を一緒に写す
4. **読み取り**：形の呼び名、寸法、尖った角、上側と下側の高さ。Claude の読みは根拠つき
5. **3 案**：絵・名前・理由・確かめ結果のカード。押すとその案に切り替わる
6. **手で微調整**：留め方、爪の本数・太さ、高さ、向き、地金、サイズ
7. **型紙と指示書**：PDF に書き出す

- 3D はドラッグで回す。問題のある爪は赤く、守られていない角には赤い印。
- すべての変更は履歴に積み、戻せる（Claude の変更も）。
- 金属は鏡面の光、石は写真から取った色。

## 石の取り込み

写真から石の縁の形を取り、実寸は 1 つの長さで合わせる。形の比率は写真、大きさはノギスか写った基準物、深さはノギス。

| 入れ方 | 使う場面 | 大きさの決め方 | 精度の見込み |
| --- | --- | --- | --- |
| 写真＋ノギス（長辺と深さ） | お店・工房 | 長辺の実寸。幅は写真の比率から（測れば上書き） | 0.1 mm 前後（評価で確かめる） |
| 写真＋1 円玉か定規 | 家・店頭の最初 | 1 円玉の直径 20 mm | 0.1〜0.3 mm（石の縁が台から浮く分、大きく写る） |
| 指輪に付いたままの石 | 家（リフォームの相談前） | 1 円玉 | 案を決めるための目安。爪で隠れた縁は Claude が推し量る。最終は店で石を外して測る |
| まとめて（平たい石） | ポートレートカットなど | 1 番の石の長辺で全部 | 試し画像で長辺の誤差 0.04 mm 以内 |

**撮り方の決まり**

- 色のある石は白い紙、無色の石は黒い紙の上で、真上から。
- 石が画面の 3 分の 1 くらいになるまで寄る。離れて撮ると淡い石は背景に溶ける。
- まとめて撮るときは、石どうしを数 mm 離す。
- 横からの写真があれば、上側と下側の高さの割合を読む。なければ深さを 3:7 で仮に置く。

**輪郭の取り方**

1. 写真全体で、明るさのむらを消してから、背景と色の違うかたまりを探す。写真の端に触れるものは石と見なさない。
2. 押された石、なければ真ん中に近いものを選ぶ。
3. その周りを切り出し、高い解像度でもう一度輪郭を取る。
4. 一番長い辺の向きを長辺とし、実寸に直す。
5. 取った輪郭は必ず写真に重ねて見せ、人が確かめられるようにする。

## 石の 3D と枠

石は「縁の形＋深さ」で作り、枠はその縁に沿わせて自動で作る。面（ファセット）は標準的なカット風に自動で付けるだけで、本物の面とは同じにしない。

**石**

- 縁（ガードル）：写真の輪郭。厚みは石の大きさの約 2%。
- 上側（クラウン）と下側（パビリオン）：深さを横からの写真の割合、なければ 3:7 で分ける。
- 色：写真の石の部分の平均色。色が薄ければ無色。

**枠**

| 部分 | 決め方 |
| --- | --- |
| 覆輪 | 縁に沿った壁。内側は縁＋0.04 mm、壁の厚み 0.5 mm。上端は石の上側に少しかかる |
| 爪 | 本数は自動（角が 3〜6 つなら角の数、細長い・大きい石は 6、それ以外は 4）。選んだ角を先に守り、残りは縁に均等に配る |
| V 字の爪 | 尖った角に。角の両側に 2 本の足、先を V 字で角を包む |
| 爪の太さ | 標準＝（0.5 ＋ 0.1 ×（石の大きさ − 1.5））× 1.15 mm。手で変えられる |
| 石座の輪 | 爪をつなぐ輪を 2 段（石の下側の途中と、腕のすぐ上） |
| 高さ | 石の一番下が指から 0.3 mm 以上離れる高さが最低。低め / 標準（＋0.5 mm）/ 高め（＋1.0 mm） |
| 向き | 長辺を指に沿って縦、または横 |
| 腕 | 甲丸。幅 2.2 mm、厚み 1.6 mm。号数から内径（内径 ＝ 13.0 ＋（号数 − 1）÷ 3 mm） |

- 形を作る処理は画面と分け、同じ入力なら同じ形が出るようにする（テストできる形）。
- まとめてのときは、全部の石を覆輪・低めで作り、指輪を並べて見せる。

## Claude の役割

> 古い所あり：3 案は作っていない。今の道具は README の「Claude の使い方」（`set_setting`・`set_shank`・`check`・`look`・`set_stones`・`propose_rule`・`ask_gap`・`gap_rule`・`ask_teacher`・`red_pen`・`propose_process`・`grade_process`）。

Claude は「石を見て、道具でその石のための指輪を組み、職人の目安で確かめて直し、理由を言う」助手。写真の読み取りは入口で、主役はこの設計と判断。

| 場面 | Claude がすること | 人に返すもの |
| --- | --- | --- |
| 石を読む | 写真と輪郭から、形の呼び名、尖った角、欠けやすそうな所、留める向きを読む。爪で隠れた縁を推し量る。ノギスの写真から数字と測った辺を読む | 読み取り表（何を・いくつ・根拠）。分からない所は「分からない」と書く |
| 3 案 | その石に合う向きの違う 3 案を考える（例：角を守る V 字の爪／覆輪／横向き・高め） | 絵・名前・理由・確かめ結果つきのカード |
| 組んで直す | 道具を自分で使って組み、確かめ、問題があれば選択肢から選んで直し、もう一度確かめる（最大 3 周） | 作業の記録と、「やったこと・確かめたこと・残っていること」 |
| 指示書 | 選んだ案の理由を短く書く | 指示書の「選んだ理由」欄 |

**道具（人のボタンと同じ関数）**

| 道具 | 入力 | 返すもの |
| --- | --- | --- |
| set\_setting | 留め方（覆輪 / 爪）、爪の位置（輪郭の番号）、本数、太さ、高さ、向き、理由 | 新しい留め方と、石の留まり |
| set\_shank | 腕の幅・厚み、断面（決まった形か線）、場所ごとの形（幅・厚み・断面・流れ）、面に彫る模様、号数、地金、理由 | 新しい寸法と重さ |
| check | なし | 問題の一覧（どこ・今の値・必要な値・理由・直し方の選択肢と見た目への影響） |
| look | 向き | 今の指輪の画像（言われた印象になっているかを見るため） |

- check は答えではなく選択肢を返す。どれを選ぶかは Claude がお客さまの希望（華奢に、手をよく使う、など）から決め、理由を残す。
- Claude の変更も履歴に積み、「この作業を全部戻す」で戻せる。
- 画面から直接 Claude API を呼ばない。小さなサーバー的な関数が API キーを持ち、道具の定義と一緒に渡す。道具の実行は画面の中。
- 通信できないときは、決まりごとから作った 3 案を「決まりごとから」と書いて出す。

## 確かめるルール

> 古い所あり：数字の出どころは、いまは帳面に「職人／公開の資料（URL）／仮」と分けて持つ。石の先を指から 0.3 mm・角から 0.9 mm・爪の間 38% は、出どころが見つからず「仮」にした（11/4）。爪の太さの式は、公開の 4 点をつなぐ線と、職人（石川）の決まりに替えた。

数字はすべて教科書・公開情報レベルの目安。設定ファイル 1 つにまとめ、職人が直した値で上書きする。画面と指示書には「目安・最後は職人が決める」と出す。

| 確かめ | 目安 | 合わないときの選択肢 |
| --- | --- | --- |
| 石の一番下と指のすき間 | 0.3 mm 以上 | 石座を高くする |
| 爪の太さ | 1ct（約 6.5 mm）で 1.0〜1.3 mm、小さな石で 0.5 mm まで（[出典](https://skyjems.ca/pages/encyclopedia-prong-wire)）。最低＝0.5 ＋ 0.1 ×（石の大きさ − 1.5）mm | 太くする |
| 爪の先の高さ | 石の上面までの高さの 75〜85%。爪がかかる長さは上側の 33〜50%（[GIA](https://www.gia.edu/jp/bench-tip-avoid-stone-loss-with-quality-assurance-benchmarks)） | 爪の先を下げる／上げる |
| 石の留まり | 標準の 4 本爪・標準の高さを 1.0× として、「本数 ÷ 4 ×（太さの比）の 3 乗 × 長さの比の逆数」。V 字の爪は足 2 本と数える。必要なのは上 1.0×、横 1.2×、手のひら側 1.4× | 太くする／本数を増やす／低くする／覆輪に |
| 爪の間隔 | いちばん空いた所が縁の周の 38% 以下 | 爪を足す |
| 尖った角 | 角から 0.9 mm 以内に爪 | 角に V 字の爪／覆輪に |
| 覆輪の壁 | 0.4 mm 以上 | 壁を厚く |

- 「留まり」は爪を片持ちの棒と見なした目安の比較で、強度計算の代わりではない。そう画面に書く。
- 選択肢には必ず「見た目への影響」を添える（例：太くすると少し重く見える）。

## 型紙と指示書

> 古い所あり：PDF ではなく、ブラウザで印刷する図面・指示書・作り方・型紙。STL は指輪ぜんたい（石座・腕・ザグり・ロウの丸み）。

1 つの PDF に 2 ページで出す。1 ページ目が指示書、2 ページ目が原寸の型紙。型紙の線は mm 単位でそのまま描き、印刷で大きさが変わらないようにする。

**指示書（何を作るかだけ）**

| 項目 | 中身 |
| --- | --- |
| 見た目 | 選んだ案の 3D の画像 |
| 石 | 形の呼び名、長辺 × 幅 × 深さ（幅を写真から出したらそう書く）、上側 / 下側の高さ |
| 留め方 | 覆輪（壁の厚み）または爪（本数、V 字の数、太さ） |
| 高さ・向き・地金・サイズ | 号数と内径 |
| 確かめた結果 | 石の一番下と指のすき間、石の留まり、残っている注意 |
| 選んだ理由 | Claude の理由（または案の理由） |
| 注記 | 「作り方・石座の削り・最終の合わせは職人が決める」 |

**原寸の型紙（1:1）**

- 黒：石の縁（写真から）。赤：覆輪の内側（点線）と外側、または爪の位置と太さ。
- 確かめの線：10 mm と 50 mm。「実際のサイズ・100%」で印刷し、定規で確かめる。
- 読みやすいように 3 倍に拡大した輪郭も並べる（「原寸ではない」と書く）。
- まとめてのときは、全部の石を番号つきで 1 枚に並べる。
- 透ける紙（トレーシングペーパー・OHP フィルム）に印刷すれば、石にかぶせてずれを見られる。

**そのほかの書き出し**

- 石座の STL（樹脂で試しにプリントするため）。「形を確かめるためのもの」と書き添える。
- 指輪のデータ（JSON）。読み込めば続きから直せる。

## 精度の証明

「写真から出した形が、本物の石に合う」を数字と実物で示す。これが作品の信用の土台になる。

1. **石 10 個の比較表**：手元の石を拡大して真上から撮り、長辺だけ入れて幅を写真から出す。ノギスで測った幅と比べ、誤差の平均と最大を出す。1 円玉で撮った場合も同じ石で比べる。
2. **型紙と石の重なり**：原寸の型紙を印刷し、本物の石を線の上に置いて拡大して撮る。
3. **本物の枠に石が収まる**：型紙に沿って職人が地金で覆輪を作り、削らずに石が入るところを撮る。樹脂プリントが早く出せれば、それも追加の証拠にする。

**ここまでに分かっていること（試作で）**

- 三角の石（長辺 8.88 mm・深さ 4.35 mm）の拡大写真：輪郭が縁に合い、尖った角 3 か所を見つけた。幅は写真から 7.52 mm。
- 同じ石をケースごと離れて撮った写真：淡い部分が背景に溶け、幅を 3.2 mm と読み違えた。→ 拡大して撮る決まりにした。
- まとめて（試し画像、平たい石 7 石）：6 石を見つけ、長辺の誤差は 0.04 mm 以内。近すぎた 1 石は見落とした。
- ここまでは自作の画像と 1 石だけ。本物のポートレートカットは、開始後に確かめる。

## 技術構成と公開の安全

形を作る処理と画像の処理はブラウザの中で完結させ、Claude とのやり取りだけを小さなサーバー的な関数に通す。

| 部分 | 使うもの |
| --- | --- |
| 画面 | TypeScript、three.js。スマホの縦画面に対応 |
| 画像の処理 | ブラウザの Canvas（背景のむら取り、かたまり探し、輪郭）。写真はサーバーに保存しない |
| 形を作る処理 | 画面と分けた関数。同じ入力で同じ形。テストを書く |
| PDF | 型紙の線は mm でそのまま描く。日本語の文字は画像として貼る |
| Claude とのつなぎ | serverless 関数 1 つ。道具の定義と写真を渡し、道具の実行は画面で |
| 公開先 | GitHub Pages 以外（例：Vercel） |

**公開しても安全にするための決まり**

- API キーは `.env` に置き `.gitignore` で除く。コミット前にキーが入っていないか確かめる仕組みを入れる。
- Claude Console で使える金額の上限を決める。公開ページは合言葉か 1 日の回数制限。制限を超えたら見本の石で動きを見せる。
- リポジトリのライセンスは MIT（2026-11-05 作者が決めた。帳面の中身もふくむ）。外から借りた画像は、それぞれの利用条件に従う。
- 使う素材は使う権利があるものだけ。見本の石の写真は作者が撮ったもの。
- コードはすべて大会期間中に新しく書く。この仕様書より前に作った試作は参考にするだけで、コードは貼り付けない。
