# 提出の概要（2026-11-06）

**継ぐ（つぐ）— 職人の判断を、蓄える。失われた技まで、組み立て直す。**

テーマ #1「あなたにしかない深さを。」。作者は宝飾の彫金職人です。

## 解決する課題

作れるかどうかの判断は、職人の頭の中にあります。爪の太さ、石の先と指の間、どこにロウを流すか。ネットや本にあるのは一般の目安だけで、工房ごとの判断は残りません。だから、デザインの絵が「作れない」と制作から何度も戻り、教えるたびに職人の手が止まります。学校では、先生の確認を長いときは 1 時間待ちます（作者の経験）。

めったに作らない技ほど、途切れます。何年もかけて作り、20 年に一度しか作り直さない技（公に知られた例では、伊勢神宮の式年遷宮の御装束神宝）には、多い人でも一生に 3 回ほどしか関われません（国土交通白書。社殿の技能者の話）。国が指定した伝統的工芸品の従業員は、約 11.5 万人（平成 10 年度）から約 4.8 万人（令和 4 年度）へ、24 年で約 6 割減りました（経済産業省の説明資料。`docs/RESEARCH-scale.md`）。

## 継ぐですること

**1. 残す（職人）。** 職人がふだんの言葉で話すと、Claude が数字つきの決まりの案にし、職人が「これでいい」を押すと帳面に残ります。だれの言葉か・いつの言葉かも一緒に。決まりが入ると、今の設計も、これまでの作品も、その決まりで確かめ直します。帳面は工房ごとに持てます。帳面のまだ決まっていない所は、Claude のほうから職人に聞きに来ます。

**2. デザインする人へ。** 手持ちの石の写真（輪郭を読む）か、よくある形から始めます。希望の言葉で頼むと、Claude が石座・腕の断面・場所ごとの太さ・彫りまで組み、帳面の決まりで自分で確かめて直します（本物の Claude に「ゴシックな感じ」と頼んだ回：Claude を 4 回・道具を 6 回・38 秒）。作れない所は、職人の言葉で、なぜ作れないか・どう直すかを教えます。爪を押して 1 本ずつ直す、寸法を 2 点で引く、地金のみの指輪の断面を手で描く（上と下で変える）、テンション（地金ごとの計算。値はこの石の場合の例）もできます。3D の形から、鋳造でも鍛造でも、作り方を自動で作り、図面・指示書・STL まで出します。

**3. 学ぶ人へ。** 言葉で聞くと、帳面の決まりから理由つきで答え、もとになった職人の言葉まで戻れます。Claude につながらなくても、帳面から探して答えます。答えのないことは、職人への質問として帳面に届きます。手の動きを、職人の手本と比べることもできます。

**4. 次の時代へ。** 作り方を隠した木目金で、残った品物などの手がかりだけから Claude が工程を組み立て、隠しておいた本当の作り方と答え合わせしました。11 工程のうち 9 にたどり着きました（手がかりから 6・もともとの知識から 3。公開の記録の回は 11 のうち 10）。「模様の試し」では、本当の手順と Claude の手順のとおりに作ったら、どんな模様になるかを計算で描いて並べます（目安の絵）。

## だれのためか

- **職人**：判断を一度話せば、教えるたびに手を止めなくてよい。工房ごとに帳面を持てる。
- **デザイナー・作る人**：描きながら、職人の判断で「作れる形」を確かめられる。
- **学ぶ人**：先生の順番を待たずに、答えのある「なぜ？」は職人の言葉まで戻って分かる。答えのない質問は、職人への質問として帳面に届く。
- **技を受け継ぐ所**：めったに作らない技の判断と作り方を、技ごとの帳面として残せる。

## これから

使ってほしいのは、学校などの教育の場と、さまざまな工房です。学ぶ人は、先生の手が空くのを待たずに、職人の言葉まで戻って「なぜ？」が分かります。工房は、職人の判断を帳面に残し、弟子やデザイナーが何度でも聞き返せるようにします。継ぐは、人から人への伝え方を置きかえるのではなく、支えます。

## 社会と経済への効き方

作り手が減るほど、一人の職人の判断の重みは大きくなります。継ぐは、その判断を帳面として残し、次の人がそこから始められるようにします。作り直しの往復が減れば、職人とデザイナーの時間が、作ることに戻ります（どれだけ減るかの数字は、まだ測っていません）。

## Claude の使い方

- **アプリの中の Claude**：Claude は答えを決めません。形を作る・確かめる・見る道具（`src/claude/tools.ts` ほか）を渡し、職人の決まりを読んで選び、理由を残す役です。寸法と「作れるか」は、帳面の決まりでプログラムが計算するので、いつも同じ答えになります。
- **作る側の Claude Code**：彫金職人が Claude Code に話しかけて作りました。大きな機能はサブエージェントが別の作業フォルダで並行に作りました。職人の目安は Skill に、API キーの混入止めと自動のテストはフックに置きました。帳面と確かめは MCP にして、Claude のアプリからも使えます。くわしくは README。

## デモについて

- 動画に映るのは、継ぐの本物の画面を本当に操作したものです。言葉で頼む場面の Claude の返事は本物です。
- 例のデータを使う画面（`?mihon` の見本）があり、中身は作り話です（画面にも出ます）。
- 金属を彫る手元の映像は、ほかの人の映像です（出典は動画の最後と README のライセンスの一覧）。
- 職人の決まり（爪の最低の太さ・三角の石は角に 1 本ずつの爪 3 本・細い溝は手で彫る など）と作り方のコツは、作者の言葉です。公開の資料の決まりは出どころの URL つき。出どころのない数字は、画面にも「仮」と出します。数字は目安で、最後は職人が決めます。
