# 提出の概要（下書き）

**継ぐ（つぐ）— ネットにない職人の判断を、形を確かめる決まりにして、次の人へ渡す。**

作れるかどうかの判断と作り方は、職人の頭の中にあります。ネットや本に書いてあるのは一般の目安だけで、AI が学習しただけでは、職人の暗黙の判断にはまだたどり着けません。何年もかけて作り、20 年に一度しか作り直さない技は、一人の職人が一生のうちに数えるほどしか関われません。

作者は宝飾の彫金職人です。出発点は、自分の仕事である指輪。最初の目標は、こうした伝統の技を残すことです。

- **職人の一言が、設計を直す**：一粒石の指輪を、ネットの公開情報だけで組むと、爪の太さは 1.66 mm。職人が「この大きさなら最低 0.7 mm」と一言話すと、Claude がそれを目安帳の決まりにし、爪は 0.80 mm になります。
- **一つの言葉が、ほかの大きさにも効く**：職人が話した 2 つの大きさの言葉から、石の大きさに合わせた線ができ、3 mm の石にも 12 mm の石にも比率で効きます。
- **一言が残る**：「これでいい」で、今の設計も、これまでの作品もすべて確かめ直し、まとめて直します。帳面は工房ごとに持て、同じ指輪を帳面ごとに比べられます。図面（正面・側面・上面・寸法）と、鋳造・鍛造の作り方（数字・道具）、3D データ（STL）も出ます。
- **現場で**：デザイナーの絵が、CAD や製作の段階で「作れない」と戻ってくる往復を、描く前に減らします。問題には「誰のどの決まりか」と直し方が付きます。
- **学校で**：先生の順番を待たなくても、答えのある「なぜ？」は帳面の職人の言葉まで戻って分かります。答えられない質問は、職人への質問になります。
- **万が一、作り方が途切れても**：残った品物と材料の手がかりから Claude が作り方を組み立て、隠しておいた本当の作り方と答え合わせします。Claude がもともと知っていたかもしれない工程は、分けて数えます。

Claude は答えを決めるのではなく、職人の決まりを読んで選び、理由を残す役です。数字は出典か職人の言葉から。目安で、最後は職人が決めます。このアプリも、彫金の職人が Claude Code に話しかけて作りました（Skill・フック・サブエージェント・MCP の使い分けは README に）。
