# 提出の概要（下書き）

**継ぐ（つぐ）— 職人の判断を、次の人へ。**

漆、焼き物、金工。国が指定した伝統工芸の作り手は、40 年あまりで約 6 分の 1 になりました（出典：伝統的工芸品産業振興協会）。作れるかどうかの判断と作り方は、職人の頭の中にあり、何年もかけて作り、20 年に一度しか作り直さない技は、一人の職人が一生で 2〜3 回しか関われません。

作者は宝飾の彫金職人です。まず自分の仕事、指輪で作りました。

- **写真 1 枚から、作れる設計と作り方まで**：石の写真の輪郭から、爪留めの一粒石の指輪を組み、作れるかを目安で確かめ、鋳造と鍛造の工程を、この形から計算した数字・道具・図面・STL で出します。言葉や絵からは Claude が形を組みます。
- **職人の一言が、全部に効く**：職人が話した一言を Claude が「目安帳」の一行にし、「これでいい」を押すと、今の設計も、これまでの作品もすべて確かめ直し、まとめて直します。次の人の設計にも同じ目安が効きます。数字で確かめられない手の決まり（ヤスリの当て方など）は、作り方のその工程に、職人の言葉のまま出ます。
- **失われた技も**：作り方が途切れた技を、残った品物の手がかりだけから Claude が組み立て、隠しておいた本当の作り方と答え合わせします。Claude が学習で知っていたかもしれない工程は「もともとの知識から」と分けて数えます。

数字は出典か職人の言葉から。目安で、最後は職人が決めます。このアプリも、彫金の職人が Claude Code に話しかけて作りました。
