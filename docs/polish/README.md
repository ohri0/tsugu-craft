提出の前に、設計（studio.html）・帳面・学ぶ・技の頁・合言葉の窓・使い方の窓・Claude につながらないときを、ヘッドレスのブラウザ（PC 1440 × 900、スマホ 390 × 844）で開き、見えるボタンを 1 つずつ押して確かめた。入口のページ（index.html）、途切れた技・模様の試し・手を比べるは、ほかの係が直しているので触っていない。
