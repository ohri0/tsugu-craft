## 職人に決めてほしいこと・まだ残っていること

1. **設計を開いて最初の 3 秒**（open-a-studio-first-seconds）：最初の見せ場が始まる前、下の欄の「今の石を使う」の下が「—」、号の欄が空、右の「腕の形」の見出しの下が空のまま一瞬見える。見せ場が始まると埋まる。直す所（生成の欄）は、いま別の係が「石なし」を足しているので触っていない。
2. **技の一覧の札の字の大きさ**（open-b-waza-card-text-size）：「途切れた技を、組み立て直す」の 4 枚だけ、説明の字が上の 7 枚より大きい（`restore.css` の `.rs-waza-card small` が 15 px）。わざとならこのまま、そろえるなら 1 行で直る。別の係の受け持ちなので触っていない。
3. **図面の「大きく見る」のボタン**（open-c-drawing-button）：図面の右下の角に少し重なる。読むのには困らない。
4. **言葉**（open-d-words）：「ノンカリブレ」（決まった寸法でない石）、「この工房のベーシック」（工房のいつもの形）は、作者が決めた言葉なので変えていない。初めての人には意味が分かりにくいかもしれない。「ノンカリブレ（決まった寸法でない石）」と添えるか、作者に聞きたい。
5. **最初に読み込む量**：設計の画面の本体は 1.17 MB（送るときは 354 KB）。three.js のぶん。速い回線なら気にならないが、スマホの遅い回線では数秒かかる。分けるのは提出のあとでよい。
6. 学ぶで、合言葉を入れていない人が例のボタンを押すと、はじめの 1 回は合言葉の窓が出る（「合言葉なしで使う」で帳面から答える）。画面には「いまは Claude なしで、帳面から探します（合言葉は右上）」と出ているので、少し食い違って見える。公開の版は入口で合言葉を聞くのでこの窓は出ない（手元で動かす人だけ）。決めた動きのままにしてある。
