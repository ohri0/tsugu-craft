## 作者を待っていること

- **API キー**：作者がクラウド環境の環境変数に `ANTHROPIC_API_KEY` と `DEMO_PASSWORD` を入れる。入れた後の新しいセッションで、`npm run dev` で `/api/claude` を確かめる。
- **作者の決まり 5〜10 個**（CAD オペレーターが戻す理由、若手に何度も言うこと）→ 聞き取りの本物の中身と動画に使う。
- **三角の石の拡大写真**（`samples/`、長辺・深さ・幅）→ 輪郭が縁に合うかの関門。
- デザイナーと CAD の往復の回数と日数。
- ColBase で選んだ画像のページの URL → README に出典。
