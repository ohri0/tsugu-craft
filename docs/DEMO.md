# デモ動画の絵コンテ（3 分以内・日本語）

大会の決まり：デモ動画は 3 分以内、日本語、実際に動いているところを中心に（スライドの発表はしない）。リポジトリは公開。
審査の人は職人ではない。最初の 20 秒で「誰の、どんな困りごとを、どう解決するか」が分かり、最後まで見たくなる流れにする。映っているものはすべて本当に動いているもの。

## 流れ（11/3 版・2）

筋：継承の難しさ（作り手が約 6 分の 1、技は頭の中、20 年に一度の技）→ 私は宝飾の彫金職人。まずは私の仕事、指輪から → 写真 1 枚から設計図と作り方まで → 確かめる・作る → 山場：職人の一言が、過去の作品と次の人の設計まで全部に効く → 記録が残る → 失われた技も（木目金）→ 継ぐのデータから作った本物 → このアプリも職人が Claude Code に話しかけて作った。
仮の動画（V コンテ 2）は、場面ごとの画面を寄せたり流したりして、字幕を本当の長さでつないだもの。撮っていない所は灰色の板、まだ作っていない画面は黄色の枠で代わりにしている。

## 画面録画の手順（Mac で、公開ページを）

準備：Chrome で https://tsugu-craft.vercel.app/studio.html（設計の画面）を開き、全画面（Control + Command + F）。録画は Command + Shift + 5 →「画面全体を収録」。マウスはゆっくり。1 場面ずつ別の録画にすると編集しやすい。

## 撮影の決まり

- 特定の会社・計画・年の名前は出さない（CLAUDE.md）。神宝づくりの話は「何年もかけて作り、20 年に一度しか作り直さない技」とだけ言う。
- お客さまの名前や札が映らないようにする。
- 使う権利のない画像・音楽は使わない。音楽を入れるなら、自分で作ったものか、利用条件がはっきりしたもの（出典を最後に出す）。
- 画面の録画は公開した URL で撮る（その場で動いていることが分かるように）。合言葉は映さない。
- 合言葉と API キーは、画面にも声にも出さない。
