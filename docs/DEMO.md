# デモ動画の絵コンテ（3 分）

審査員は職人ではない。前提知識のない人が、最初の 20 秒で「誰の、どんな困りごとを、どう解決するか」が分かり、最後まで見たくなる流れにする。
映っているものはすべて本当に動いているもの。まだの所は「これから」と言う。

## 撮影の決まり

- 特定の会社・計画・年の名前は出さない（CLAUDE.md）。「何年も」とぼかす（作者の確認が取れたら「7 年ほど」）。
- お客さまの名前や札が映らないようにする。
- 公開の画像は、出典を書けば使える所（ColBase など）のものだけ。正しい説明を付け、最後に出典を出す。
- 画面の録画は、公開した URL で撮る（その場で動いていることが分かるように）。
