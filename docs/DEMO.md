# デモ動画の絵コンテ（3 分以内・日本語）

大会の決まり：デモ動画は 3 分以内、日本語、実際に動いているところを中心に（スライドの発表はしない）。リポジトリは公開。
審査の人は職人ではない。最初の 20 秒で「誰の、どんな困りごとを、どう解決するか」が分かり、最後まで見たくなる流れにする。映っているものはすべて本当に動いているもの。

## 流れ

筋：ジュエリーが「作れるか」を確かめ、「どう作るか」を道具まで示す → でも一点物は繰り返しでは覚えられない → だから一つずつ記録を残し、次の人がそこから始める → 途切れた技も手がかりから組み立て直せる。

## 撮影の決まり

- 特定の会社・計画・年の名前は出さない（CLAUDE.md）。神宝づくりの話は「何年もかけて作り、20 年に一度しか作り直さない技」とだけ言う。
- お客さまの名前や札が映らないようにする。
- 使う権利のない画像・音楽は使わない。音楽を入れるなら、自分で作ったものか、利用条件がはっきりしたもの（出典を最後に出す）。
- 画面の録画は公開した URL で撮る（その場で動いていることが分かるように）。合言葉は映さない。
- 合言葉と API キーは、画面にも声にも出さない。
