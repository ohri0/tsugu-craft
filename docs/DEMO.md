# デモ動画の絵コンテ（3 分以内・日本語）

大会の決まり：デモ動画は 3 分以内、日本語、実際に動いているところを中心に（スライドの発表はしない）。リポジトリは公開。
審査の人は職人ではない。最初の 20 秒で「誰の、どんな困りごとを、どう解決するか」が分かり、最後まで見たくなる流れにする。映っているものはすべて本当に動いているもの。

## 流れ（11/3 版）

筋：大きな事実（作り手が約 6 分の 1）→ ジュエリーの往復の課題 → 写真 1 枚から設計図と作り方まで → 確かめる・作る → 20 年に一度の技 → 山場：職人の一言が、過去の作品と次の人の設計まで全部に効く → 継ぐのデータから作った本物 → このアプリも職人が Claude Code に話しかけて作った。
仮の動画（V コンテ）は、場面ごとの画面と字幕を本当の長さでつないだもの。撮っていない所・まだ作っていない画面は、何が入るかを書いた板で代わりにしている。

| --- | --- | --- | --- |

## 撮るもの（チェック）

- [ ] 手元：絵を描いては消す（作者、iPhone を台に固定）
- [ ] 画面録画：公開ページで、本物の Claude が動くところ（なぜ継ぐ・生む・絵の読み込み・確かめる・作る・図面・記録に話す・組み立て直す）
- [ ] 本物の指輪：最初の三角の石の一粒石の指輪を、継ぐの図面と作り方（鍛造）で手で作る。作る途中の手元を 2〜3 秒ずつ。言葉は「継ぐのデータから作った」（鋳造したとは言わない）
- [ ] ナレーション（作者の声、静かな部屋で。iPhone のボイスメモでよい）

## 画面録画の手順（Mac で、公開ページを）

準備：Chrome で https://tsugu-craft.vercel.app/ を開き、全画面（Control + Command + F）。録画は Command + Shift + 5 →「画面全体を収録」。マウスはゆっくり。1 場面ずつ別の録画にすると編集しやすい。

| 番号 | 台本の場面 | 操作 |
| --- | --- | --- |
| A | 0:08 往復の図 | 右上の「なぜ継ぐ」→ 最初の図を 8 秒映す（赤い点が往復する） |
| B | 0:30 生む | 下の欄に「華奢に。毎日つける。石を大きく見せたい」→「生む」。右の「Claude の作業」が一行ずつ出て、指輪が変わるまで |
| C | 0:30 絵から | 右の「デザインの絵」→ 0:00 で描いた絵の写真を選ぶ →「生む」 |
| D | 0:55 石の写真 | ページを開き直す（最初に写真 → 輪郭 → 指輪の見せ場が出る）。続けて「よくある形」でオーバル・ペアを押す。最後に「甲丸・平打ちの指輪」を 2 秒 |
| E | 1:10 確かめる | 上の「確かめる」→「手で変える」の爪の太さを左いっぱいへ → 赤くなる →「直す」の青いボタン → 緑の「このまま作れます」 |
| F | 1:30 作る | 上の「作る」→ 鋳造と鍛造を切り替え →「詳しく」を開く → 点線の言葉（湯道など）を押す → 道具の札を 1 つ押す |
| G | 1:30 図面 | 「図面・指示書を印刷」→ 図面と作り方に印 →「印刷」→ 出た図面を 3 秒映す。左上の「ワイヤー」「シェード」「レンダー」も切り替える |
| H | 1:55 20 年の図 | 「なぜ継ぐ」→ 2 つ目の図まで下へ（帯がのびる） |
| I | 2:25 話して残す | 「作る」の下の「この作品の記録を残す」→ 名前 →「話す」でコツを話す →「記録する」→ 工程ごとに分かれる → 作り方を開き直して「前の記録から」 |
| J | 2:25 組み立て直す | 右上の「組み立て直す」→ 手がかりから組み立て → 答え合わせ（木目金） |

1 コマずつ撮った滑らかな 3D の回転（レンダー・シェード・ワイヤー、各 6 秒）は、つなぎや背景に使える。

## 撮影の決まり

- 特定の会社・計画・年の名前は出さない（CLAUDE.md）。神宝づくりの話は「何年もかけて作り、20 年に一度しか作り直さない技」とだけ言う。
- お客さまの名前や札が映らないようにする。
- 使う権利のない画像・音楽は使わない。音楽を入れるなら、自分で作ったものか、利用条件がはっきりしたもの（出典を最後に出す）。
- 画面の録画は公開した URL で撮る（その場で動いていることが分かるように）。合言葉は映さない。
- 合言葉と API キーは、画面にも声にも出さない。
