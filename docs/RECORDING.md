# 声の録り方（11/8 の録音のために）

動画の声を、石川さんご自身の声で録ります。
録った音は、Claude が行ごとに切り分けて、雑音を少し消して、動画に入れます。

## 録る前に

- 静かな部屋で。エアコン・換気扇・冷蔵庫の音が小さい所。
- スマホのボイスメモで録ります。
- スマホは口から 20〜30 cm。机に置いてもよいです。録っている間は、スマホを持ちかえたり、さわったりしない。
- 紙をめくる音・机をたたく音が入らないように。

## 読み方

- 下の表の順に、上から読みます。
- 行と行の間は、2 秒くらい黙ります（ゆっくり 2 つ数える）。
- まちがえたら、そこでやめて 2 秒黙り、その行を頭からもう一度読みます。
  - あとに読んだ方を使います。何度読み直してもかまいません。
- 「（間を開けて）」と書いた所は、行の途中で少し間を開けます。
- （ ）の中のひらがなは読み方です。声には出しません。
- いつもの話す速さで大丈夫です。急がなくてよいです。

## 録った音の数

- 1 本の長い録音で大丈夫です（全部で 3〜4 分くらい）。
- 途中で休みたいときは、何本かに分けてもかまいません。そのときは、どこで分けたかだけ教えてください（例：「1 本目は n19 まで」）。
- 一部だけ録り直したいときは、その行だけを録れば大丈夫です（例：「n5 と n6 を録り直した」）。

## 録った音の置き場所

次のどちらかで、Mac に送ってください。

1. iCloud Drive の「継ぐ動画」フォルダに入れる。
2. AirDrop で Mac に送る。

ファイルの名前は、そのままで大丈夫です。

## そのあと（Claude がします）

- 行ごとに切り分けて、雑音・口の「プチッ」という音を少し消します。声そのものは、強くいじりません。
- 切り分けがあやしい所があれば、お知らせします。全部をつないだ確かめ用の音（`_check.m4a`）も作るので、耳で確かめられます。

## Claude へ（切り分け方）

- 録音を `video/work/voice/` の外のどこか（例：`video/work/rec/`）に置いて、次を走らせる。何本かのときは、録った順に並べて渡す。

  ```
  video/work/.venv/bin/python -I video/voice_split.py video/work/rec/録音.m4a
  video/work/.venv/bin/python -I video/voice_split.py video/work/rec/1.m4a video/work/rec/2.m4a
  video/work/.venv/bin/python -I video/voice_split.py video/work/rec/n5n6.m4a --lines n5,n6
  ```

- できる物：`video/work/voice/n<番号>.wav`（48 kHz、前後 0.15 秒の余白）、きれいにする前の同じ所 `_raw/n<番号>.wav`、表 `_split_report.txt`、確かめの音 `_check.m4a`（選んだ所を 0.6 秒の間で並べた）。
- すでに `n<番号>.wav` があるときは上書きしない（`_new_<時刻>/` に書く）。表と確かめの音を聞いてよければ `--force` でもう一度（前のものは `_backup_<時刻>/` に写す）。
- 表の ⚠ の行は、`_check.m4a` のその秒を聞いて確かめる。読み直しを取りちがえたときは、その行だけ `--lines` で録り直してもらうのが早い。
- 試し：`video/work/.venv/bin/python -I video/voice_split_test.py`（仮の声をつないだ録音で、行の当て方を確かめる。本物の `voice/` には書かない）。
- そのあと `final_build10.py` を走らせると、`own_voice()` が前後の無音を切って大きさをそろえ、作者の声で組み直す。
