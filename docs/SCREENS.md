# 画面の構成

継ぐは「職人が残す → 設計を確かめる → 次の人に渡す」の道具。使う人ごとに場所を分け、どの画面からも同じ名前・同じ順でほかの場所へ行ける。下のタブは 4 つ：設計・帳面・学ぶ・技。

| 場所 | 使う人 | すること | アドレス |
| --- | --- | --- | --- |
| 入口 | はじめての人・審査の人 | 何の道具か・なぜ要るか・何ができるか。「はじめる」で設計へ | `/` |
| **設計** | デザイナー・職人 | 生む → 確かめる → 作る → 記録（いちばん使う画面） | `studio.html` |
| **帳面** | 職人 | いちばん上に職人の決まりの札（決まり・職人の言葉・名前と日・見せた動画）。次に「Claude から質問が 1 つあります」（指輪の帳面のまだ決まっていない所）。その下に、帳面を印刷・手本を撮る・思いついたことを話して残す・届いている質問（あるときだけ） | `app.html#ledger` |
| **学ぶ** | 次の人 | 開くと「職人に聞く」（言葉で聞く。例のボタンつき。合言葉がなくても帳面から答える）。「手の動きで比べる」は、そこから開く 2 つ目の入口 | `app.html#learn`・`#learn/hands` |
| **技** | だれでも | 大きな札 3 つから選ぶ：指輪の石留め（設計へ）・魚々子（図 → Claude の質問 → 帳面）・途切れた技を、手がかりから組み立て直す（木目金。結果があれば先に出す。長い注意はたたむ） | `app.html#waza`・`#waza/nanako`・`#waza/rebuild` |
| なぜ継ぐ | だれでも | デザインと CAD の往復の図、20 年に一度の技の図（重ねて出す） | 設計の右上・入口の中 |

## 設計（studio.html）の中

上のタブ（1〜4 のキーでも）で場面を変える。左は見る向き・目盛り・寸法、3D の左上で「ワイヤー／シェード／レンダー」。

1. **生む**：作る物（一粒石の指輪／甲丸・平打ちの指輪）、石（写真かよくある形）、デザイナーの絵、希望の言葉 →「生む」。
2. **確かめる**：作れるか。目安を外れた所は赤、直し方のボタン、手で変える。**職人の決まり**：話す（Claude が決まりの案に）か数字で書く →「これでいい」で、今の設計と記録のすべての作品を確かめ直し、まとめて直す。
3. **作る**：鋳造／鍛造の工程と数字・道具・「詳しく」・言葉の意味。工程の中に、職人の手の決まりと前の記録のコツ。図面・作り方・型紙の印刷、STL。
4. **記録**：作った物ごとの記録（職人が話すと工程ごとのコツに分かれる）。新しい決まりで直した跡。帳面の印刷。記録がなければ見本の作品（職人の作品ではないと名前に出る）。

## 合言葉がないとき

Claude を使う所（希望の言葉・絵から生む、話した決まり、Claude に直してもらう、組み立て直す）は合言葉が要る。技の聞き取りは、合言葉がなければ決まった問いと数字を読むしくみで動く（画面に「Claude なし」と出る）。それ以外は合言葉なしで全部動く。山場は「数字で書く」と見本の作品で試せる。組み立て直すは、公開の記録（実際に組み立てた結果）があればそれを出す。

## 前のアドレス

前の名前で来ても、新しい場所に送る（`src/app/routes.ts`）：`#see` → `#learn/hands`、`#ask` → `#learn`、`#keep` → `#ledger`、`#rebuild` → `#waza/rebuild`、`#waza/ring` → `#ledger`（`?gap=` はそのまま）。
