# 灰の丸紋（shashin）
入れ方：写真のような見た目の説明だけ（作り方の言葉なし）　正しい答え：描く
（propose_restoration：40 秒）

## 案 1
灰色の地に小さなくぼみを作り、白い物をはめこんで平らに研ぎ、丸だけ磨き、地はざらざらで灰緑の色にした、という作り方が考えられる。ただ、手がかりは写真3枚だけで、地と丸の材料が分からないので、どの工程も推し量りの案にとどまる。帳面は指輪の石留めなど別の技の話が多く、使ったのは彫りの深さの決まりだけで、それも参考程度にしている。
1. 地（じ）の形を作る［もともとの知識］
   まず、灰色の地になる板や器の形を作ると考えられる。地が金属か、焼き物か、漆などかは、写真からは決められない。
   分からない：地の材料が何か分からない。それによって、この先の工程がすべて変わる。
2. 丸の場所にくぼみを作る
   白い丸が地と同じ高さに見えるので、地に小さなくぼみを作り、そこへ別の白い物を入れた（はめこみ、象嵌（ぞうがん）のような作り方）かもしれない。丸は米つぶくらいで、ばらばらに散っている。この工房では毛彫りの深さをコンマ何ミリの単位と見ている。くぼみが要るなら、この技でも浅いくぼみで足りるかもしれないが、別の技の話なので、深さは試して決める。
   分からない：本当にはめこみかどうか分からない。くぼみの深さ、形、作り方（彫る・打つ・穴をあける）も分からない。
3. 白い物を入れる［もともとの知識］
   くぼみに白い物を入れると考えられる。白い物が金属か、石や貝か、釉薬（うわぐすり）や漆のようなものかは分からない。はめこみではなく、地そのものの色を丸だけ変えた作り方かもしれない。
   分からない：白い物の材料と、入れ方（打ちこむ・流しこむ・焼きつける）が分からない。
4. 面を平らにそろえる
   横から光を当てても丸が地と同じ高さに見えるので、白い物を入れたあと、地といっしょに削ったり研いだりして高さをそろえたと考えられる。
   分からない：削ったのか、はじめから同じ高さに入れたのか分からない。
5. 地をざらざらにし、灰緑の色を出す
   地は灰色ですこし緑っぽく、表がざらざらで光が鈍い。地の表を荒らしたり、色をつける処理（色上げ、さびつけのようなもの）をしたりしたかもしれない。古くなって自然にこうなった色かもしれない。
   分からない：わざと作った色か、古くなってついた色か分からない。荒らす方法も、色の出し方も、丸を磨く前か後かも分からない。
6. 丸の所だけ磨く
   丸の所だけ、つるっと光っているので、地はざらざらのまま、丸だけを磨いたと考えられる。白い物がもともとつるっとした材料なのかもしれない。
   分からない：丸だけ磨いたのか、材料の違いで自然にそう見えるのか分からない。地を荒らす工程との順番も分からない。
（predict_pattern：22 秒）

### 模様の見込み（案 1・絵 shashin-first）：描く
1枚の地に白い丸をはめこみ、地を荒らして色を出す技とみて、板の表の飾りに置きかえた。
灰緑のざらっとした地に、小さな明るい丸が散らばった絵になると思われる。ただし、丸だけが光っている感じは出ないかもしれない。
- plate（工程 1）四分一の板を 1 枚用意する　仮：地の材料は分からない。灰色で緑っぽい色になるので、色が近い四分一を仮に使った。金属だと決めたわけではない。
- zogan（工程 2）明るい色の材料を丸くはめる（象嵌）　仮：白い物の材料は分からないので、明るい色の材料にした。くぼみの深さは厚みの0.1、丸の半径は板の幅の0.02（米つぶくらい）、幅の中に12個と仮に決めた。
- ishime（工程 5）石目の細かな点を打つ　仮：点の半径は板の幅の0.005、幅の中に40個と仮に決めた。荒らし方は分からない。
- color（工程 5）色を出す：薬で色を出す（煮色のように）　仮：わざとつけた色か、古くなってついた色かは分からない。薬で色を出したと仮に決めた。
表せないこと：丸の所だけを磨いてつるっとさせる工程は描けない。石目が丸の上にもかかって描かれるかもしれない。丸がばらばらに散っている並び方は、そのとおりには描けない。地や白い物が焼き物・漆・石・貝などだった場合のちがいも描けない。光り方、手ざわり、古くなってついた色かどうか、器の形も表せない。
絵：明るさのばらつき 35.2・描くのに 616 ms

試した結果（地をざらざらにし、灰緑の色を出す）：ok　【架空】細かい点の鏨で打ったら、写真のような鈍い光り方になった。
（propose_restoration：42 秒）

## 案 2
灰色の地に小さなくぼみを作り、白い物を入れて平らに研ぎ、地を細かい点の鏨で打ってざらざらにし、丸だけ磨いた、という作り方が考えられる。地のざらざらは職人の試しで光り方が近づいたが、色、丸の材料、工程の順番はまだ推し量りの案にとどまる。
前からの違い：細かい点の鏨で打つと鈍い光り方が出た、という職人の試した結果を、地をざらざらにする工程に書き入れ、地は鏨で打てる金属かもしれない、と書き足した。色までは確かめられていないので、そこは分からない所として残した。やめた工程はない。
1. 地（じ）の形を作る
   まず、灰色の地になる板や器の形を作ると考えられる。職人が細かい点の鏨（たがね）で打って写真に近い光り方が出たので、地は鏨で打てる金属かもしれない。ただ、試しに使った材料と元の品の材料が同じとは限らない。
   分からない：地が金属か、焼き物や漆などか。金属ならどの金属か。厚さも分からない。
2. 丸の場所にくぼみを作る
   白い丸が地と同じ高さに見えるので、地に小さなくぼみを作り、そこへ別の白い物を入れた（はめこみ、象嵌（ぞうがん）のような作り方）かもしれない。丸は米つぶくらいで、ばらばらに散っている。この工房では毛彫りの深さをコンマ何ミリの単位と見ている。この技でも浅いくぼみで足りるかもしれないが、別の技の話なので、深さは試して決める。
   分からない：くぼみが本当にあるのか。深さ、くぼみの形（底が平らか丸いか）、何で作ったか。
3. 白い物を入れる［もともとの知識］
   くぼみに白い物を入れると考えられる。白い物が金属か、石や貝か、釉薬（うわぐすり）や漆のようなものかは分からない。はめこみではなく、地そのものの色を丸だけ変えた作り方かもしれない。
   分からない：白い物の材料。はめこみか、色を変えただけか。
4. 面を平らにそろえる
   横から光を当てても丸が地と同じ高さに見えるので、白い物を入れたあと、地といっしょに削ったり研いだりして高さをそろえたと考えられる。
   分からない：何で削ったか、研いだか。この工程と、地を鏨で打つ工程のどちらが先か。
5. 地を細かい点の鏨で打ってざらざらにし、灰緑の色を出す
   地は灰色ですこし緑っぽく、表がざらざらで光が鈍い。職人が細かい点の鏨で打ったら、写真のような鈍い光り方になった。地の表はこのように細かい点を打ってざらざらにしたのかもしれない。平らにそろえたあとに打つと、地のざらざらが残る順になると考えられる。
   分からない：職人の言葉は光り方の話で、灰緑の色まで出たかははっきりしない。色が打つだけで出るのか、色をつける処理や古びが要るのかは試して決める。丸のまわりを避けて打ったのか、全体を打ってから丸を磨いたのかも分からない。
6. 丸の所だけ磨く
   丸の所だけ、つるっと光っているので、地はざらざらのまま、丸だけを磨いたと考えられる。白い物がもともとつるっとした材料なのかもしれない。地を鏨で打つと丸にも当たるかもしれないので、打ったあとに丸だけ磨き直したのかもしれない。
   分からない：何で磨いたか。磨いたのか、材料がもともと光るのか。
（predict_pattern：15 秒）

### 模様の見込み（案 2・絵 shashin-v2）：描く
1枚の地の板に白い丸をはめこみ、地を細かい点で打つ技として、板の表の飾りに置きかえた。
灰緑の、細かい点でざらざらした地に、米つぶくらいの明るい丸が地と同じ高さで並ぶ模様になりそうです。ただし、丸だけが光る見た目は、この絵には出ないと思われます。
- plate（工程 1）四分一の板を 1 枚用意する　仮：前と同じく、灰緑に近い四分一を仮に使った。金属だと決めたわけではない。
- zogan（工程 2）明るい色の材料を丸くはめる（象嵌）　仮：前と同じ値。白い物は明るい色の材料、くぼみの深さは厚みの0.1、丸の半径は板の幅の0.02（米つぶくらい）、幅の中に12個と仮に決めた。
- ishime（工程 5）石目の細かな点を打つ　仮：前と同じく、点の半径は板の幅の0.005、幅の中に40個と仮に決めた。
- color（工程 5）色を出す：薬で色を出す（煮色のように）　仮：試しで色まで出たかははっきりしないので、前と同じく薬で色を出したと仮に決めた。
表せないこと：丸の所だけ磨いてつるっと光らせる工程は描けません。絵では、点の鏨が丸にも当たって、丸もざらざらに見えるかもしれません。白い物が石や貝・釉薬・漆の場合や、はめこまずに色だけ変えた場合の見た目も描けません。丸がばらばらに散っている様子は、ならべた丸に近い形でしか描けないかもしれません。古びてついた色も描けません。
絵：明るさのばらつき 35.2・描くのに 713 ms
