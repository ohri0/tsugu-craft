# 鉄地の黒漆金粉（urushi）
入れ方：金属に漆（金属の飾りではない）　正しい答え：描かない
（propose_restoration：40 秒）

## 案 1
鉄の地に黒い漆をぬり、かたまる前に金の粉を雲のようにまいて、上から漆でおおい、研いで金を出し、みがいてつやを出す、という案です。書きつけの「鉄地に漆をかけ、金を蒔き、研ぎ出す」と、品物の見た目をもとに考えたもので、確かな作り方ではありません。かため方や回数などは試して決める必要があります。
1. 鉄の地をととのえる
   鉄の鐔の表を、漆がのるようにととのえる。欠けた所で、黒い膜のすぐ下に鉄の赤さびの地が見えるので、さびた地のまま漆をかけたのかもしれない。ただ、そのさびが、作るときからあったのか、あとでできたのかは分からない。
   分からない：さびをわざと付けたのか、落としてから漆をかけたのか、あとでできたさびなのかは分からない。油を落とすかどうか、どう落とすかも分からない。
2. 黒い漆を下にぬる
   書きつけに「鉄地に漆をかけ」とある。欠けた所の膜は金属ではないので、黒い漆の膜と考えられる。何度かぬり重ねて、黒い地を作るのかもしれない。
   分からない：何回ぬるか、一回の厚さ、黒い色を何で出すかは分からない。試して決める。
3. 漆をかためる［もともとの知識］
   漆はしめった所でかたまる、という一般の知識から出した工程。鉄の上の漆は、熱でかためる方法もあるかもしれない。手がかりにはどちらとも書いていない。
   分からない：しめりけでかためるか、熱でかためるか、どちらか分からない。温度や日数も分からない。試して決める。
4. 金の粉を雲のように蒔く
   書きつけに「金を蒔き」とある。品物には金色の細かな粉が雲のように散らしてある。かたまる前の漆に、金の粉を雲の形に散らすと考えられる。
   分からない：粉の細かさ、粉をまく前に漆をぬるか、どの道具でまくかは分からない。
5. 粉の上から漆をぬり重ねる
   書きつけに「研ぎ出す」とあり、品物は粉の所も平らなので、粉の上を漆でおおってから研いだのかもしれない。おおう漆の色（黒か、すけるものか）は分からない。
   分からない：何回ぬり重ねるか、どの漆を使うかは分からない。
6. 研いで金を出す
   書きつけの「研ぎ出す」から、かたまった漆を研いで、下の金の粉を出すと考えられる。こうすると、粉の所も周りと同じ平らになり、品物の見た目と合う。
   分からない：何で研ぐか（炭か砥石か）、どこまで研ぐかは分からない。研ぎすぎると金が消える。
7. みがいてつやを出す
   品物の表は真っ黒でつやがある。研いだあと、みがいてつやを出したのかもしれない。みがき方は手がかりになく、もともとの知識からの推し量り。
   分からない：何でみがくか、漆をうすくすりこむかは分からない。
（predict_pattern：8 秒）

### 模様の見込み（案 1・絵 urushi-first）：描かない
漆をぬり、金の粉をまいて研ぎ出す、漆の技です。金属を重ねる技でも、金属の板の表を彫る・打つ・はめる技でもないので、どちらの計算にも合いません。
この計算では絵にできません。黒いつやのある地に、金の粉が雲のように平らに見える見た目になると考えられますが、試して確かめる必要があります。
表せないこと：黒い漆の膜、金の粉の雲のような散らし方、研ぎ出した平らな面、みがいたつや、鉄の地のさび

試した結果（黒い漆を下にぬる）：ng　【架空】さびを落とさずに塗ったら、膜が浮いてはがれた。
（propose_restoration：38 秒）

## 案 2
鉄の地のさびを落としてから黒い漆をぬり、金の粉を雲のようにまいて上から漆でおおい、研いで金を出す、という案です。さびを残してぬったらはがれたという試した結果から、地のととのえ方を変えました。これは試して確かめるための案で、確かな作り方ではありません。
前からの違い：さびを落とさずにぬったら膜がはがれたという試した結果を受けて、最初の工程を「さびを落としてととのえる」に変えました。黒い漆をぬる工程は、ととのえた地にぬる形に変え、ほかの工程は前の案のままです。
1. 鉄の地のさびを落としてととのえる
   漆をぬる前に、鉄の表のさびを落とす。さびの上にそのままぬったら膜が浮いてはがれた、という試した結果があるので、少なくとも浮いたさびやもろいさびは落とす方がよいと考えられる。ただ、品物の欠けた所では膜のすぐ下に赤さびの地が見える。これがあとからできたさびなのか、薄くしっかりしたさびをわざと残したのかは分からない。まずは、こすって落とす方法から試すとよいかもしれない。
   分からない：どこまで落とすか（地金が出るまでか、しっかり付いた薄いさびは残すか）は分からない。品物の下のさびが作るときからあったのかも分からない。
2. 黒い漆を下にぬる
   ととのえた鉄の地に、黒い漆をぬる。書きつけに「鉄地に漆をかけ」とあり、欠けた所の膜は金属ではないので、黒い漆の膜と考えられる。前に試したときのはがれは、さびを残したことによると考えられるので、地をととのえてからもう一度試す。何度かぬり重ねるのかもしれない。
   分からない：はがれた理由が、さびだけなのか、漆のかため方やぬり方にもあるのかは分からない。ぬる回数も分からない。試して決める。
3. 漆をかためる［もともとの知識］
   漆はしめった所でかたまる、という一般の知識から出した工程。鉄の上の漆は、熱でかためる方法もあるかもしれない。手がかりにはどちらとも書いていない。かため方で、鉄へのつき方が変わるかもしれない。
   分からない：しめらせてかためるか、熱でかためるか、分からない。何度で、どれだけの時間かも分からない。試して決める。
4. 金の粉を雲のように蒔く
   書きつけに「金を蒔き」とある。品物には金色の細かな粉が雲のように散らしてある。かたまる前の漆に、金の粉を雲の形に散らすと考えられる。
   分からない：粉をまくのが、下の漆がどのくらいかたまった時か分からない。粉の細かさも分からない。
5. 粉の上から漆をぬり重ねる
   書きつけに「研ぎ出す」とあり、品物は粉の所も平らなので、粉の上を漆でおおってから研いだのかもしれない。
   分からない：おおう漆の色（黒か、すけるものか）は分からない。ぬる回数も分からない。
6. 研いで金を出す
   書きつけの「研ぎ出す」から、かたまった漆を研いで、下の金の粉を出すと考えられる。こうすると、粉の所も周りと同じ平らになり、品物の見た目と合う。
   分からない：何で研ぐか、どこまで研ぐかは分からない。
7. みがいてつやを出す
   品物の表は真っ黒でつやがある。研いだあと、みがいてつやを出したのかもしれない。みがき方は手がかりになく、もともとの知識からの推し量り。
   分からない：何でどうみがくか分からない。
（predict_pattern：7 秒）

### 模様の見込み（案 2・絵 urushi-v2）：描かない
鉄の地に漆をぬり、金の粉をまいて研ぎ出す技です。飾りは金属を重ねたものでも、板を彫る・打つ・はめるものでもなく、漆の膜の中にあります。どちらの計算にも合いません。
この計算では絵にできません。黒い地に金の粉が雲のように散る見た目になりそうですが、確かめるには小さな切れ端で試すのがよいと思います。
表せないこと：漆の黒い膜とつや。雲のようにまいた金の粉と、研いで出した金の見え方。さびの落とし方と、漆の鉄へのつき方（はがれるかどうか）。漆のかため方（しめらせるか、熱か）。粉の細かさ。
