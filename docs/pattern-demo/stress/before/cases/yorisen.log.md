# より線透かしの髪飾り（yorisen）
入れ方：より線（細い線をよって渦にして、透かしの板にする）　正しい答え：描く
（propose_restoration：40 秒）

## 案 1
細い銀の線をよってより線にし、渦に巻いて太い線の枠の中に詰め、ロウ付けでつなぎ、渦の真ん中に銀の粒を付けて作った、という案です。手がかりは少なく、粒の作り方や仕上げはもともとの知識からの推し量りです。つなぎ方や粒の付け方は、まず残った品物を見て確かめる必要があります。
1. 細い銀の線をそろえる
   蔵から出た、よる前の細い銀の線の束のような線を用意する。よりやすくするため、焼きなまして柔らかくしておくとよいかもしれない。焼きなましのあとは、この工房では槌目や木目金でゆっくり冷ますと判断している。この技でも、ゆっくり冷ます方が曲がりにくいかもしれない。
   分からない：線の太さ、焼きなましの温度と時間は分からない。試して決める。
2. 線をよる
   細い線を何本か合わせてよって、より線にする。残った髪飾りの渦がより線でできていること、よる前の線の束が出たことから考えた。よったあとに少し平らにつぶしたかどうかは、手がかりからは分からない。
   分からない：何本をよるか、よりの向きと強さ、よったあとにつぶしたかどうかは分からない。
3. 太い線で外の枠を作る
   太い線を曲げて外の枠の形にし、つなぎ目をロウ付けで閉じると考えられる。枠が太いことは残った品物から言える。つなぎ目をロウ付けすることは、もともとの知識からの推し量り。ロウ付けのあとは、この工房では指輪や覆輪でゆっくり冷ますと判断している。この技でも、そうすると曲がりにくいかもしれない。
   分からない：枠の線の太さと断面の形、つなぎ目の閉じ方は分からない。
4. より線を渦に巻く
   より線を、ピンセットなどで中心から外へくるくると巻いて、渦の形をたくさん作る。残った品物に渦が並んでいることから考えた。
   分からない：渦の大きさ、巻く数、巻く道具は分からない。
5. 渦を枠の中に詰める
   巻いた渦を枠の中にすき間なく並べ、互いに押し合って止まるようにする。渦の間が透けて見え、裏に板がないように見えることから、渦どうしと枠とがじかにつながっていると考えた。
   分からない：詰めるときに台や板の上で組んだのか、どう押さえたのかは分からない。
6. 渦と枠をロウ付けする
   渦どうし、渦と枠が触れる所をロウ付けしてつなぐと考えられる。蔵から出た小さな板の切れがロウかもしれないので、それを小さく切って使った可能性がある。ロウ付けのあとは、この工房の判断にならい、ゆっくり冷ます方が曲がりやロウ目の割れが減るかもしれない。
   分からない：板の切れが本当にロウかどうか、ロウを置く方法、使った溶き剤（フラックス）は分からない。
7. 銀の粒を作る［もともとの知識］
   小さな銀の切れを熱で溶かして丸め、小さな粒を作ると考えられる。粒があることは残った品物から言えるが、作り方は手がかりになく、もともとの知識からの推し量り。
   分からない：粒の大きさ、溶かす方法と台は分からない。試して決める。
8. 渦の真ん中に粒を付ける
   一つ一つの渦の真ん中に、銀の粒を一つずつ付ける。粒の位置は残った品物から言える。ロウで付けたのか、熱で溶かしてじかに付けたのかは分からない。
   分からない：粒の付け方、渦のロウ付けと同時か後か、順番は分からない。
9. よごれを落として仕上げる［もともとの知識］
   ロウ付けでできた黒いよごれや溶き剤を落とし、みがいて仕上げる。手がかりにはなく、もともとの知識からの推し量り。
   分からない：よごれを落とす液、みがき方は分からない。
（predict_pattern：14 秒）

### 模様の見込み（案 1・絵 yorisen-first）：描かない
この技は、より線を渦に巻いて枠に詰め、ロウ付けで組む透かし細工です。重ねた層の模様でもなく、地の板が無いので、1 枚の板の表の飾りでもありません。渦を彫った線や透かしに置きかえると、別の技の絵になってしまうので、描きません。
この計算では絵にできません。粒は板の上の粒金なら描けますが、この品物には粒を載せる板が無いため、粒だけを描くこともしませんでした。
表せないこと：より線のよりの目、渦の巻き方と並び、太い線の枠、板の無い透けた組み方、ロウ付けのつなぎ目、渦の真ん中の銀の粒、焼きなましやゆっくり冷ますことの効きめ、仕上げの光り方。

試した結果（渦と枠をロウ付けする）：ng　【架空】ろうが多すぎて、渦の間がろうで埋まってしまった。

## 案 2

前からの違い：試した結果で、ロウが多すぎて渦の間が埋まったため、ロウ付けの工程を、とても小さく刻んだロウを触れる所だけに置くやり方に変えました。その前にロウを細かく用意する工程を足し、粒を付けるときもロウを少なくする考えを加えました。

   蔵から出た、よる前の細い銀の線の束のような線を用意する。よりやすくするため、焼きなまして柔らかくしておくとよいかもしれない。この工房では、槌目や木目金で、焼きなましたあとはゆっくり冷ますと判断している。この技でも、ゆっくり冷ます方が曲がりにくいかもしれない。

   分からない：渦どうしがどのくらい強く押し合っていたかは分からない。
6. ロウをとても小さく刻んで用意する
   前の試しで、ロウが多すぎて渦の間が埋まった。そこで、ロウをとても小さなかけらか、やすりで削った粉のようにして、少しずつ置けるようにしておくとよいかもしれない。蔵から出た小さな板の切れがロウなら、それを細かくして使った可能性がある。粉にする方法は、もともとの知識からの推し量り。
   分からない：板の切れが本当にロウかは分からない。どのくらい小さくすれば埋まらないかも、試して決める。

### 模様の見込み（案 2・絵 yorisen-v2）：描かない
この技は、より線を渦に巻いて枠に詰め、触れる所をロウでつなぐ作り方です。裏に板が無く、線そのものが形になります。重ねた層の模様でも、1 枚の板の表の飾りでもないので、計算には合いません。板に穴をあけて線を彫った絵にすると、本当の作り方とちがう見え方になってしまうため、描きません。
絵は出しません。前の試しで困った「ロウで渦の間が埋まる」ことは、計算では見込めません。刻んだロウを少しずつ置く案がうまくいくかは、小さな切れ端で試して確かめるのがよさそうです。
表せないこと：より線のより目、渦の形と並び方、渦の間から向こうが見えること、ロウの量と、渦の間が埋まるかどうか、渦の真ん中の銀の粒、枠の形、ゆっくり冷ましたときの曲がり方は描けません。
