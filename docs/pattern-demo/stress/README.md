### 正直さ

- 13 の技・2 回の案で、案の工程と「次に確かめること」に、手がかりにない数字は 0（画面と同じ見張り）。数は手がかりにある「5 つ」「10 くらい」などだけ。帳面の数（毛彫りの深さ 0.1〜0.3 mm など）を使うときは、「別の技の数字なので、この技でも近いかもしれないが、試して決める」と書いた。
- 見込みの数（枚数・深さ・数）は、どれも assumed に「絵のための仮の値」と書いた。2 回目は「前と同じ」「試した結果に合わせて、ここだけ変えた」と書いた。
- 食いちがう手がかり（mujun）では、2 つの道を両方案に残し、「どちらかはまだ決められない」と書いた。試した結果（溝に銀をはめても奥まで通らない）を受けて、2 回目の絵を重ねて立てる道に変えた。
- 直す前の通しでは、試しの道具（`scripts/pattern-stress-cases.ts` の工程の探し方）が、架空の結果を別の工程につけてしまった所が 5 つあった（道具の誤り。探す言葉を直した）。そのときも Claude は、銀筋の小皿で「職人の言葉は象嵌の話に読める。どちらを試したかを、まず職人に聞く」と書いた。後の通しでも 1 つ（銀筋の小皿で「地の板を作る」につけた）残ったが、Claude は象嵌の試しと読み、象嵌の道を外した。
- 漆（urushi）と蝶番（chotsugai）は、2 回とも描かずに、理由（金属の表の飾りではない・しくみの技で表は磨くだけ）を書いた。蝋型（rougata）は「鋳る手順そのものは描けない。鋳たあとの表を板の飾りに置きかえた。鋳てつぶれる量は計算しない」と書いた。

## まだ弱い所（職人に伝えること）

（2026-11-08 追記）下の 1・2・3・5 番目は、計算と道具の言葉を直した。記録の見込み（Claude の答え）はそのままなので、ここの絵は前と同じ。新しい値は、次に Claude に頼んだ見込みから使われる。

- 数の意味：道具に `count`（品物 1 つ・板全体の数）を足した。丸・くぼみ・葉・花・ふくらみ・透かし・粒・七宝の区切りは、count があれば、ちょうどその数を置く（「10 ほど」なら 10）。幅の中の数で並べたいときだけ、今までどおり `across`。count の無い古い記録は前と同じ絵。
- 線の場所：彫る線に `outline`（前に打ち出した帯・ふくらみのふち＝高さが半分の所にそった線）を足した。平らに残した板のふちには引かない。
- 葉の鏨：重ねる計算の彫る・打ち出すに、`leaves`（葉の形・向きは 1 つずつちがう）と `petals`（5 枚の花びら）を足した。打って削ると、葉の形の輪が出る。
- 層の厚さ：重ねる計算の stack と、板の飾りの重ねた plate に、`thickness`（材料ごとの厚さの割合）を足した。空なら今までどおり同じ厚さ。
- 渦金の星の先（前の 8 つの技）：ねじった棒を何本か横に並べてつなぐ（twist の `across`）を足した。2 本以上なら、つなぎ目に星が丸ごと出る。1 本のときは、今までどおり板のふちで半分に切れる。

前に書いた弱い所：

- **数の意味**（shashin）：across は「幅の中に並ぶ数」で、板全体ではその 2 乗。説明を足したが、Claude は「10 ほど」に幅の中 8 を選び、板全体で 60 ほどの丸になった。散らす操作では、板全体の数で受け取る方がよいかもしれない。
- **線の場所を指せない**（utsuwa）：「波のふちに線」と言われても、線は帯の背か、等しい間にしか引けない。Claude は 6 本を「帯の両ふち」のつもりで選んだが、絵の線は等しい間に並ぶ。
- 葉の形の鏨（konoha）は、重ねる計算では丸いくぼみでしか描けない（Claude はそう書いた）。
- より線の渦の真ん中に粒を 1 つずつ置く、はできない（Claude は「散らす」で近づけ、そう書いた）。
- 重ねた板の層は同じ厚さだけ（kasanebori で、Claude は「赤銅を薄めにする案は描けない」と書いた）。唐草は 1 つの決まった形で、列の数が少ないと渦が列のさかいで切れる。
- 打ち出しの低い波（rojin の案 2、厚みの 15%）は、見えるが、うすい。
- 案の道具が「次に確かめること」を空で返し、自動の出し直しで通った（65 秒）。ふだんの範囲だが、出し直しのぶん待つ。
