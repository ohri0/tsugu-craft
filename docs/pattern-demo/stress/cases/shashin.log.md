# 灰の丸紋（shashin）
入れ方：写真のような見た目の説明だけ（作り方の言葉なし）　正しい答え：描く
（propose_restoration：33 秒）

## 案 1
灰色ですこし緑っぽい、ざらざらの地に、白い丸が地と同じ高さで散らばっている品物です。白い丸は、はめこんだのかもしれませんし、色を付けずに残したのかもしれません。手がかりは写真だけなので、工程はどれも推し量りの案です。まず実物を見て、材料と丸のさかい目を確かめるのがよいと考えられます。
1. 地になる材料を用意する
   全体が灰色ですこし緑っぽく、表がざらざらで光が鈍い品物です。何の材料（金属か、焼き物か、ほかの物か）かは、写真からは決められません。まず材料を決めるところから始める必要があると考えられます。
   分からない：材料が何か分からない。灰色と緑っぽさが、材料そのものの色か、あとから付けた色かも分からない。
2. 白い丸を置く場所を決める
   白い丸は、ならばずに、ばらばらに散っています。決まった模様ではなく、ばらばらになるように置いたのかもしれません。たまたまできた跡かもしれません。
   分からない：わざと置いたのか、作る途中で自然にできたのか分からない。
3. 白い丸を地と同じ高さに作る
   横から光を当てても、丸は地と同じ高さに見えます。そのため、上に盛ったのではないと考えられます。考えられる道は二つあります。一つは、地に小さなくぼみを作って白い物をはめこみ、平らにする道（象嵌のような、はめこみ）です。もう一つは、色を付ける前に丸の所を覆って守り、そこだけ元の色を残す道です。どちらかはまだ分かりません。
   分からない：はめこみか、覆って色を残したのか分からない。白い物が何かも分からない。
4. 地を灰色っぽく、ざらざらにする［もともとの知識］
   地はざらざらで、光が鈍いです。表を荒らしたり、薬や熱で色を付けたりして、灰色や緑っぽい色にしたのかもしれません。このやり方は手がかりからではなく、もともとの知識から考えたものです。
   分からない：荒らし方も色の付け方も分からない。丸を作る前か後かも分からない。
5. 丸の所だけをつるっと仕上げる
   丸の所だけが、つるっと光っています。丸の材料がもともと光りやすいのかもしれません。丸だけを磨いたのかもしれません。地がざらざらのままなので、地を磨かずに丸だけが光るやり方が要ると考えられます。
   分からない：丸を磨いたのか、材料の性質で光るのか分からない。
（predict_pattern：17 秒）

### 模様の見込み（案 1・絵 shashin-first）：描く
はめこむ道を選び、灰色の地の板に白い丸をばらばらにはめ、地を細かな点で荒らす形に置きかえました。
暗い灰色のざらっとした地に、明るい丸がばらばらに散って、地と同じ高さに見える絵になりそうです。ただし、丸の上にも細かな点が重なり、丸のつるっとした感じは出ないかもしれません。
- plate（工程 1）暗い色の材料の板を 1 枚用意する　仮：材料が分からないので、灰色に近い暗い色の材料として仮に描く
- zogan（工程 3）明るい色の材料を丸く、ばらばらにはめる（象嵌）　仮：白い物は名前が分からないので明るい色の材料にした。丸の半径は幅の0.03、幅の中におよそ8つ、深さは厚みの0.1と仮に決めた
- ishime（工程 4）石目の細かな点を打つ　仮：点の半径は幅の0.008、幅の中に30ほど、深さ0.05と仮に決めた。丸の前か後か分からないので、工程の順のとおり後にした
表せないこと：本当の材料と、灰色や緑っぽい色が材料の色か、あとから付けた色か。丸の所を覆って元の色を残す、もう一つの道。丸だけがつるっと光る仕上げ（絵では、地を荒らす点が丸の上にもかかって見えるかもしれません）。光の鈍さや手ざわり。
絵：明るさのばらつき 44.9・描くのに 671 ms

試した結果（地を灰色っぽく、ざらざらにする）：ok　【架空】細かい点の鏨で打ったら、写真のような鈍い光り方になった。
（propose_restoration：48 秒）

## 案 2
灰色ですこし緑っぽい地に、白い丸が地と同じ高さで散らばっている品物です。細かい点の鏨で地を打つと鈍い光り方が出たので、そこを軸にした案です。丸は、はめこみか、色を付けずに残したか、打たずに残したのかもしれません。色の出し方はまだ推し量りです。
前からの違い：細かい点の鏨でうまくいった試しの結果に合わせて、地のざらざらの工程を鏨で打つやり方にし、色付けは別の工程に分けました。丸の作り方に、鏨で打たずに残す道を足しました。焼きなますなら、この工房の帳面にならってゆっくり冷ます工程を、要るときだけのものとして足しました。
1. 地になる材料を用意する
   全体が灰色で、すこし緑っぽい品物です。職人が細かい点の鏨（たがね）で打ったら、写真に近い鈍い光り方になりました。そのため、鏨の跡が残る材料が候補になると考えられます。ただ、品物そのものの材料は、まだ写真からは決められません。
   分からない：品物の材料は分からない。試しに使った材料と同じかどうかも分からない。
2. 白い丸を置く場所を決める
   白い丸は、ならばずに、ばらばらに散っています。決まった模様ではなく、ばらばらに置いたのかもしれません。たまたまできた跡かもしれません。
   分からない：わざと置いたのか、たまたまできたのか分からない。
3. 白い丸を地と同じ高さに作る
   横から光を当てても、丸は地と同じ高さに見えるので、上に盛ったのではないと考えられます。道は三つ考えられます。一つ目は、小さなくぼみに白い物をはめこんで平らにする道（はめこみ）。二つ目は、色を付ける前に丸の所を覆って、元の色を残す道。三つ目は、鏨で地を打つときに丸の所だけ打たずに残す道です。三つ目なら、丸がつるっとしている訳も説明できるかもしれません。地を打つ前にやる工程と考えました。
   分からない：三つの道のどれか分からない。丸が白い訳（別の材料か、元の色か）も分からない。
4. 地が硬ければ、焼きなます（要るときだけ）
   鏨で打つ前に、材料をやわらかくするために焼きなますことがあるかもしれません。この技で要るかどうかは分かりません。この工房では、槌目や木目金で、焼きなましたあとは水で急に冷やさず、ゆっくり冷ますと判断しています。この技でも、焼きなますならゆっくり冷ますのがよいかもしれません。
   分からない：焼きなましが要るかどうか、何度でどれくらいかは分からない。試して決める。
5. 地を細かい点の鏨で打って、ざらざらにする
   職人が細かい点の鏨で打ったら、写真のような鈍い光り方になりました。この打ち方を地のざらざらの作り方として続けます。丸を打たずに残す道をとるなら、丸のまわりをよけて打つことになります。
   分からない：打ったあとも丸が地と同じ高さに見えるかは分からない。打つ深さや点の細かさは試して決める。
6. 地を灰色ですこし緑っぽい色にする［もともとの知識］
   試しで分かったのは光り方で、色のことは分かっていません。薬や熱で色を付けたのかもしれませんし、材料そのものの色や、古くなってできた色かもしれません。このやり方は手がかりからではなく、もともとの知識から考えたものです。
   分からない：色を付けたのか、材料の色か、古くなった色か分からない。付けたなら、何を使い、何度で、どれくらいかも分からない。
7. 丸の所だけをつるっと仕上げる
   丸の所だけが、つるっと光っています。丸を打たずに残したなら、もとの平らな面がそのまま光っているのかもしれません。はめこんだなら、丸の材料がもともと光りやすいか、丸だけを磨いたのかもしれません。地のざらざらを消さずに、丸だけを光らせるやり方が要ると考えられます。
   分からない：磨いたのか、もとの面が残っただけなのか分からない。
（predict_pattern：19 秒）

### 模様の見込み（案 2・絵 shashin-v2）：描く
1枚の板の表の飾りとして描きます。白い丸は三つの道のうち、絵にできる「はめこみ」で描き、石目で地を打ち、最後に色を出します。
暗い地に細かい点が一面にあって鈍く光り、その中に明るい丸がばらばらに見える絵になりそうです。ただ、丸の上にも点が重なって描かれるかもしれません。
- plate（工程 1）暗い色の材料の板を 1 枚用意する　仮：品物の材料が分からないので、前の案と同じく暗い色の材料として仮に描きます
- zogan（工程 3）明るい色の材料を丸く、ばらばらにはめる（象嵌）　仮：前の案と同じ値です。白い物は明るい色の材料にしました。丸の半径は幅の0.03、幅の中におよそ8つ、深さは厚みの0.1と仮に決めました
- ishime（工程 5）石目の細かな点を打つ　仮：前の案と同じく、点の半径は幅の0.008、幅の中に30ほど、深さは0.05と仮に決めました
- color（工程 6）色を出す：薬で色を出す（煮色のように）　仮：色を付けたのかどうかは分かりませんが、工程にあるので、薬で色を出したとして仮に描きます
表せないこと：丸の所を覆って元の色を残す道と、丸だけ打たずに残す道は描けません。この絵では石目が丸の上にも打たれます。焼きなましとゆっくり冷ますこと、緑っぽい色合い、丸だけをつるっと磨くことも描けません。
絵：明るさのばらつき 54.3・描くのに 847 ms
