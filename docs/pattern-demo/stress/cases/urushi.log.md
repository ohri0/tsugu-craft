# 鉄地の黒漆金粉（urushi）
入れ方：金属に漆（金属の飾りではない）　正しい答え：描かない
（propose_restoration：42 秒）

## 案 1
鉄の地に黒い漆を塗り重ね、金粉を雲のように蒔き、研いで平らに出し、磨いてつやを出す、という流れが考えられる。書きつけと、平らでつやのある表から、塗る・蒔く・研ぐの大きな流れはわりと強く言えるが、さびの扱い、粉の上に漆を塗るか、乾かし方や磨き方は推し量り。どれも試して確かめるための案。
1. 鉄の地を整える
   鐔の形にした鉄の表をならす。書きつけに「鉄地に漆をかけ」とあるので、地は鉄だと考えられる。表をどこまで平らにするか、どう磨くかは手がかりにない。
   分からない：どの道具で、どこまで平らにするかは分からない。試して決める。
2. 鉄の表に赤さびを出す（そうしたかもしれない）
   欠けた所で、黒い膜の下に鉄の赤さびの地が見える。漆がよくつくように、わざとさびを出したのかもしれない。ただ、あとから膜の下でさびただけかもしれない。
   分からない：わざと出したさびか、あとからできたさびかは分からない。どう出したか、どれくらい出したかも分からない。
3. 黒い漆を塗り重ねる
   書きつけの「漆をかけ」と、表が真っ黒でつやがあること、膜が金属ではないことから、黒い漆を塗ったと考えられる。何度か塗っては乾かすのは、もともと知っていることからの推し量り。
   分からない：何回塗るか、どんな漆か、黒の色をどう出したかは分からない。鉄に塗った漆を熱で焼きつけたかどうかも分からない。試して決める。
4. 漆を乾かす［もともとの知識］
   漆は湿り気のある所で固まる、ともともと知っている。塗るたびに乾かすと考えた。手がかりには乾かし方は書かれていない。
   分からない：湿り気、温かさ、何日おくかは分からない。試して決める。
5. 金粉を雲のように蒔く
   書きつけに「金を蒔き」とあり、品物には金色の細かな粉が雲のように散らしてある。漆がまだ乾ききらないうちに粉を蒔くと、粉がつくと考えられる。蒔く時と道具は、もともと知っていることからの推し量り。
   分からない：粉の細かさ、どれだけ蒔くか、雲の形をどう作るか、何で蒔くかは分からない。
6. 粉の上から漆を塗りこめる［もともとの知識］
   粉の所も平らなので、粉を漆でおおってから研いだのかもしれない。研ぎ出しのやり方として、もともと知っていることから足した。
   分からない：粉の上に塗るのが黒い漆か透けた漆か、何回塗るかは分からない。
7. 研いで金粉を出す
   書きつけに「研ぎ出す」とあり、粉の所も平らなので、表を研いで、金粉を漆の面と同じ高さに出したと考えられる。
   分からない：何で研ぐか、水をつけるか、どこで止めるかは分からない。研ぎすぎると金粉が消えるので、試して見きわめる。
8. 磨いてつやを出す［もともとの知識］
   表は真っ黒でつやがあるので、研いだあとに磨いてつやを出したと考えられる。磨き方は手がかりにないので、もともと知っていることからの推し量り。
   分からない：何で磨くか、磨く前に薄く漆をすりこむかどうかは分からない。
（predict_pattern：9 秒）

### 模様の見込み（案 1・絵 urushi-first）：描かない
この技の模様は、鉄の上に塗った漆と、漆に蒔いた金粉で出ます。金属を重ねる技でも、金属の板の表を彫る・打つ・はめる技でもありません。漆を塗る・粉を蒔く・研ぎ出す、という操作は計算に無いので、無理に絵にしませんでした。
この計算では見込みを描けません。工程のとおりなら、黒くつやのある面に、金の細かな粉が雲のように平らに出る、と考えられます。
表せないこと：黒い漆の膜とつや。金粉を雲のように散らした形。粉を漆でおおってから研ぎ出し、同じ高さにそろえること。下地の赤さび。乾かし方や磨き方。鐔の形。

試した結果（黒い漆を塗り重ねる）：ng　【架空】さびを落とさずに塗ったら、膜が浮いてはがれた。
（propose_restoration：44 秒）

## 案 2
鉄の地から浮いたさびを落とし、黒い漆を薄く塗り重ね、金粉を雲のように蒔き、研いで平らに出し、磨いてつやを出す、という流れが考えられる。塗る・蒔く・研ぐの大きな流れは書きつけからわりと強く言えるが、鉄に漆をはがれないようにつける下ごしらえは、まだ分かっていない。どれも試して確かめるための案。
前からの違い：さびの上に塗ったら膜がはがれた、という試した結果を受けて、塗る前に浮いたさびを落とす工程に変え、わざと赤さびを出す工程はやめた。黒い漆を塗る工程は、さびを落とした面に薄く塗るように変えた。欠けた所の赤さびがもとからの下地かどうかは、小さな切れ端でくらべて確かめる。
1. 鉄の地を整え、浮いたさびを落とす
   鐔の形にした鉄の表をならし、浮いたさびや粉のようなさびを落とす。職人が試したとき、さびを落とさずに塗ったら膜が浮いてはがれたので、塗る前にさびを落とすのが大事だと考えられる。書きつけの「鉄地に漆をかけ」から、地は鉄だと考えられる。
   分からない：さびをすべて落とすのか、浮いたさびだけ落として固くついた薄いさびは残すのかは分からない。欠けた所の赤さびが、もとからあったのか、あとからできたのかも分からない。落とし方（ブラシ、ヤスリ、砥石など）も試して決める。
2. 黒い漆を薄く塗り重ねる
   さびを落とした鉄の表に、黒い漆を塗る。書きつけの「漆をかけ」と、表が真っ黒でつやがあり、膜が金属ではないことから、黒い漆だと考えられる。前はさびの上に塗ってはがれたので、今度はさびを落とした面に塗って、つき方を見る。薄く塗っては乾かすのは、もともと知っていることからの推し量り。
   分からない：さびを落としただけで膜がつくかは、まだ試していない。鉄に漆をよくつけるために、熱をかけて漆を焼きつけるやり方もあると、もともと知っているが、手がかりにはない。何度塗るか、どれくらいの厚さかも分からない。試して決める。
3. 漆を乾かす［もともとの知識］
   漆は湿り気のある所で固まる、ともともと知っている。塗るたびに乾かすと考えた。手がかりには乾かし方は書かれていない。
   分からない：湿り気の加減、温度、時間は分からない。鉄の上で熱をかけて固めるのか、湿り気で固めるのかも分からない。試して決める。
4. 金粉を雲のように蒔く
   書きつけに「金を蒔き」とあり、品物には金色の細かな粉が雲のように散らしてある。漆がまだ乾ききらないうちに粉を蒔くと、粉がつくと考えられる。蒔く時と道具は、もともと知っていることからの推し量り。
   分からない：粉の細かさ、蒔くときの漆の乾き具合、蒔く道具は分からない。
5. 粉の上から漆を塗りこめる［もともとの知識］
   粉の所も平らなので、粉を漆でおおってから研いだのかもしれない。研ぎ出しのやり方として、もともと知っていることから足した。
   分からない：粉の上に漆を塗るのか、粉をつけたあとそのまま研ぐのかは分からない。塗るなら黒い漆か、すき通った漆かも分からない。
6. 研いで金粉を出す
   書きつけに「研ぎ出す」とあり、粉の所も平らなので、表を研いで、金粉を漆の面と同じ高さに出したと考えられる。
   分からない：何で研ぐか（炭、砥石など）、水を使うか、どこで研ぎ止めるかは分からない。研ぎすぎると下の鉄が出るかもしれない。
7. 磨いてつやを出す［もともとの知識］
   表は真っ黒でつやがあるので、研いだあとに磨いてつやを出したと考えられる。磨き方は手がかりにないので、もともと知っていることからの推し量り。
   分からない：磨く物、漆をすりこんで磨くかどうか、何度くり返すかは分からない。
（predict_pattern：9 秒）

### 模様の見込み（案 2・絵 urushi-v2）：描かない
この技の模様は、鉄の上に塗った漆の膜の中に金粉を蒔き、研いで出すものです。重ねた金属の層の模様でも、金属の板の表を彫る・打つ・はめる飾りでもありません。漆の膜も金粉の蒔き方も、この計算にはないので、絵にしません。
この計算では見込みの絵を出せません。仕上がりは、小さな切れ端で塗る・蒔く・研ぐを試して確かめるのがよさそうです。
表せないこと：黒い漆の膜とつや、雲のように散らした金粉、研いで平らに出した様子、さびを落とした鉄の地と漆のつき方は、どれもこの計算では描けません。
