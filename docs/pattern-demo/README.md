# 模様の見込み：架空の技で、はじめから通した記録（2026-11-07）

職人の問い「この手順で作ると、どんな模様になるか」に、木目金だけでなく、どの技でも答えられるかを確かめた記録。
職人の求め：「模様の試しくらい、全部ちゃんと出てくれたらいい。本当に自分がやるときも、これぐらい綺麗に出てきてくれたら」（木目金の模様の試しの頁くらい）。
そして「重ねる系ばっかりじゃん。全く別のやつも再現できるといい」。

- **技はどれも、この世にない作り話**。手がかりの文には【架空】と書いた。本当の答えはない。
- 流れは画面と同じ：手がかりを入れる → Claude が作り方の案を出す（`propose_restoration`。職人の帳面も渡す） → Claude が案の手順を計算の操作に置きかえる（`predict_pattern`） → 計算が表と断面を描く。
- 計算は 2 つ。Claude が最初の操作で選ぶ。
  - 重ねる技（最初が `stack`）：重ねた層がどう動くか（`src/rebuild/pattern-sim.ts`）。
  - 重ねない技（最初が `plate`）：1 枚の板の表を、彫る（毛彫り・蹴彫り・片切彫り）・打つ（魚々子・石目・槌目）・透かす・打ち出す・象嵌・粒金・七宝で変える（`src/rebuild/pattern-relief.ts`）。凹凸は光の当たり方で、材料は色で描く。
  - どちらにも合わない技は描かない（月影留め）。
- Claude の返事は、本物の Claude（画面と同じ `api/claude.ts` の関数）から受け取ったまま。手を加えていない。
- 絵は**形だけの見込み**。金属の本当の流れ・熱・割れは計算しない。枚数・深さ・回数は、手順に書かれていないので Claude が絵のために仮に決めた値（「仮」）。作り方の数字ではない。最後に決めるのは職人。

作り直し方：`npx tsx scripts/pattern-demo.ts <.env のある所> [技の id ...]`（Claude を呼ぶ）、絵だけなら `npx tsx scripts/pattern-demo.ts --render`。
手がかりは `scripts/pattern-cases.ts`、技ごとの案と操作のくわしい記録は `cases/<id>.log.md`、記録のファイル（画面の「ファイルを読み込む」で開ける）は `cases/<id>.json`、見込みを頼んだ順の答えは `cases/<id>.predictions.json`。
画面の流れ：開発用のサーバーを立てて `node scripts/pattern-flow-shots.cjs <URL の頭> <技の id>`。

くせのある手がかり（とても短い・とても長い・食いちがう・英語まじり など）と、ばらばらな技 13（重ねて彫る・蝋型・七宝・打ち出しの器・より線・漆・蝶番）で、わざと荒く通した記録は `stress/README.md`。
そこで、重ねた板の表を彫る（plate に重ねた金属）・地を全部抜く透かし・より線（粒を線に詰める）・小さな渦の道すじ・ばらばらの丸い象嵌・七宝の線の金属を足した。

## 技ごとの結果

### 1. 雨垂れ銀（amadare）— 3 つの金属に穴をあけて叩く（重ねる技）

- 手がかり：表に、雨のしずくのような丸い目が同じ間で並び、目の中に黒・白・赤の輪／裏は平ら／覚え書き「赤銅、銀、銅を重ね、火にて一つとなし、錐にて浅く穴を穿ち、打ち平む。のち煮て色を揚ぐ」／職人の見立て「穴の深さで輪の数が変わるのでは」
- 案 1（9 手順）→ 見込み 1：赤銅・銀・銅を 3 枚（仮に厚さ 0.5:0.5:3。「浅い穴でも銅に届き、三色の輪が出るという案の見込みに合わせるため」）→ つなぐ → 丸い穴（仮に深さ 35%）→ 平らに → 削る → 煮色。絵 `amadare-first-top.png`（白い輪と赤い芯）
- 架空の結果「浅い穴では白と赤の輪が一組だけ。深くあけた所は輪が何重にも重なった」を入れ、見込み 1 を作り直し：3 つの地金をくり返して 12 枚（仮）、深さ 20%（「浅い穴では白と赤の輪が一組だけ出たという試した結果に合わせ」）。絵 `amadare-top.png`
- 案 2：「表から錐で穴を開ける（浅すぎない深さで）」。見込み 2：仮の値は前と同じ（「前の案から変えたのは穴の深さだけ」）、深さ 54%（「上の 2 組（6 枚）を通りぬけて、3 組目の赤銅の中で止まる」）。絵 `amadare-v2-top.png`
- 案 1 は白と赤の輪が一組の目、案 2 は黒・白・赤の輪が二組ほど重なる目。どちらにも赤が出て、見た目ははっきりちがう。

#### 2026-11-08 作り直した：赤い輪が出ない絵は、案と食いちがっていた

- 職人の声：「赤い輪がある方がかわいい。赤が出ない絵はかわいそう」。前の案 1 の絵（9 枚・浅い穴で赤い芯。職人が「可愛い」と言った絵）は `before/amadare-top.png`。
- 前の通しでは、案 1 の絵は赤が出なかった（`before3/amadare-first-top.png`：同じ厚さ 3 枚・深さ 40%、`before3/amadare-top.png`：作り直して 50%）。案 1 のあらまし自身が「黒・白・赤の輪の目になる」と言っているのに、絵だけがそうならなかった。計算は正しい（同じ厚さ 3 枚なら、銅は厚みの 2/3 から下。50% の穴は届かない。テストに残した）。弱かったのは指示：仮の値を、案の言う見た目に合わせることと、層の深さの数え方を書いていなかった。
- 直したこと：Claude への指示（`patternPrompt`）に 2 つ足した。① 穴をあけて平らにすると、穴の底までに通った層が輪になる。同じ厚さの n 枚なら、上から k 枚目は厚みの (k−1)/n から始まる。層が薄いほど、同じ深さで通る層がふえる。② 仮の値は、工程の言葉（浅く など）と、案が言う品物の見た目の両方に合うものを。合わないときは、どちらに合わせたかを書く。
- 架空の試した結果も変えた。前の「浅い穴では赤い輪が出ない」は、案 1 の絵から赤を消し、案 2 だけに赤を残す話だった。今は「浅い穴では白と赤の輪が一組だけ。深くあけた所は輪が何重にも重なった」（職人の見立て「穴の深さで輪の数が変わる」にそう話）。どちらも作り話。
- 手がかり 4 つはそのまま。本物の Claude で、案 1 → 見込み 1 → 結果 → 見込み 1 の作り直し → 案 2 → 見込み 2 を、はじめから通し直した。返事には手を加えていない。前の絵は `before3/` に残した（`flow-10.png`・`flow-12.png` も）。

### 2. 霞刃の小刀（kasumi）— 2 種の鋼を重ね直し、溝を刻んで叩く（重ねる技）

- 操作：重ねる（仮に 7 枚）→ つなぐ → 重ね直し 4 回 → まっすぐな溝 → 平らに → のばす（1/2）→ 削る → 酸
- 絵：`kasumi-top.png`・`kasumi-section.png`。はしごの帯の中の線はなめらかな細い線に、帯の間は、のばした向きに縦に流れる細い線になった（夜の見直しで、まるいまだらが無くなった）。

### 3. 渦金の帯留め（uzu）— 重ねた棒をねじり、平たくして削る（重ねる技）

- 操作：重ねる（仮に 16 枚）→ つなぐ → ねじる（3 回）→ 平らに → 削る（30%）
- 絵：`uzu-top.png`。棒のふちに層が集まる星の先と、その間の入れ子の花形が、半回りごとにくり返す。1 本の棒なので、星の先は板のふちで半分に切れて見える（下の「できないこと」）。

### 4. 市松縞の小箱（ichimatsu）— 縞の板を立てて、四角に切って互い違いに（重ねる技）

- 操作：重ねる（仮に 12 枚）→ 横にして層のふちを表に（4 本）→ 四角に切って 1 つおきに回す（6）→ つなぐ → 平らに → 削る
- 絵：`ichimatsu-top.png`。1 つの四角に細い縞が 8 本ほど、さかいはまっすぐ。

### 5. 輪打ち金筋（wauchi）— 魚々子と金の象嵌（重ねない技）

- 手がかり：黒い地に、けしの実ほどの輪が列に並ぶ／金の細い筋が波のように流れ、地と同じ高さ／覚え書き「赤銅の地に、筋を彫りて金を伏せ、打ち込みて平らにす。のち輪の鏨にて地を打ちつめ、煮て黒くす」／見立て「金を先にはめないと、輪を打つときに筋がゆがむのでは」
- 案（10 手順）。見込み：赤銅の板 → 金を波の線ではめる（仮に 5 本）→ 魚々子を列に（幅の中に 30）→ 煮色
- 絵：`wauchi-top.png`・`wauchi-section.png`（断面で金が地に埋まっているのが見える）。画面の「重ねない技の例を見る」で開ける（`research/restore/sample-moyou-surface.json`）。
- 計算は、魚々子をはめた金の所はよけて打つとした（仮）。Claude は「金の筋の上も輪を打ったのか、よけたのかは分からない」と表せないことに書いた。

### 6. 花透かしの縁彫り板（sukashibori）— 透かしと毛彫り・片切彫り（重ねない技）

- 見込み：銀の板 → 花びらの形を切り抜く（幅の中に 4）→ 毛彫りでふちに 2 本 → 片切彫りで短い線を散らす（12）→ 色は出さない
- 絵：`sukashibori-top.png`。花は後ろの暗い地が透け、ふちの 2 本の線と、花の間のあいた所に、片側だけ光る面をもつ草の株。彫りの深さは、職人の帳面の「彫りの深さ」から Claude が選んだ（「職人の帳面から」の印）。

### 7. 粒金槌目の留め具（tsubukin）— 槌目と粒金（重ねない技）

- 見込み：金の板 → 丸い槌の跡（仮に深さ 8%・半径 0.03）→ 金の粒を 7 つの房にして並べる（仮に 3）
- 絵：`tsubukin-top.png`。浅いくぼみの面と、光る粒の房。ろうの有無は描けないと、Claude が書いた。

### 8. 月影留め（tsukikage）— 描かないのが正しい技

- 手がかり：銀の指輪に乳白色の丸い石、地から彫り起こした小さな爪で留める／見立て「石の下に光を返す細かな線」
- 重ねない技の計算ができたあとも、Claude は**描かない**と答えた：「まわりの地に彫りや打ちの飾りはありません。石の下の細い線は、あるかどうかが見立てにとどまり、あっても石の下にかくれます」。表に飾りの無い石留めは、描かずにそう言う。

## この計算でできないこと（職人に伝えること）

- 形だけの見込み。金属の本当の流れ・熱・割れ・溶けは計算しない。色は絵の色（仮）で、本当の色あいではない。
- 数（枚数・深さ・回数・大きさ）は Claude が絵のために仮に決める。前の案の見込みがあれば同じ値にそろえるよう頼むが、最初の案では、仮の値しだいで絵は大きく変わる。
- 刃を斜めに研ぐ、品物の形に曲げる、石を留める、は描けない。
