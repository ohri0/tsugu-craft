# 模様の見込み：架空の技で、はじめから通した記録（2026-11-07）

職人の問い「この手順で作ると、どんな模様になるか」に、木目金だけでなく、どの技でも答えられるかを確かめた記録。

- **技はどれも、この世にない作り話**。手がかりの文には【架空】と書いた。本当の答えはない。
- 流れは画面と同じ：手がかりを入れる → Claude が作り方の案を出す（`propose_restoration`。職人の帳面も渡す） → Claude が案の手順を計算の操作に置きかえる（`predict_pattern`） → 計算（`src/rebuild/pattern-sim.ts`）が表と断面を描く。
- Claude の返事は、本物の Claude（画面と同じ `api/claude.ts` の関数）から受け取ったまま。手を加えていない。
- 絵は**形だけの見込み**。金属の本当の流れ・熱・割れは計算しない。枚数・深さ・回数は、手順に書かれていないので Claude が絵のために仮に決めた値（「仮」）。作り方の数字ではない。最後に決めるのは職人。

作り直し方：`npx tsx scripts/pattern-demo.ts <.env のある所>`（Claude を呼ぶ）、絵だけなら `npx tsx scripts/pattern-demo.ts --render`。
手がかりは `scripts/pattern-cases.ts`、技ごとの案と操作のくわしい記録は `cases/<id>.log.md`、記録のファイル（画面の「ファイルを読み込む」で開ける）は `cases/<id>.json`。

## 技ごとの結果

### 1. 雨垂れ銀（amadare）— 3 つの金属に穴をあけて叩く

- 手がかり：表に、雨のしずくのような丸い目が同じ間で並び、目の中に黒・白・赤の輪／裏は平ら／覚え書き「赤銅、銀、銅を重ね、火にて一つとなし、錐にて浅く穴を穿ち、打ち平む。のち煮て色を揚ぐ」／職人の見立て「穴の深さで輪の数が変わるのでは」
- 案 1（8 手順）：三つの地金を用意 → 面をきれいに（もともとの知識） → 重ねて火で一つに → 焼きなましてゆっくり冷ます（職人の帳面から） → 表から浅く穴を彫る → 打って平らに → 表と裏をととのえる → 煮て色を揚げる
- 操作 1：重ねる（赤銅・銀・銅を仮に 9 枚）→ つなぐ → 表から丸い穴（仮に深さ 25%）→ 平らに → 色を出す（煮色）
- 架空の結果「浅い穴では赤い輪が出ない」を入れた案 2：穴を「銅の層まで届く深さ」に変えた。操作 2：重ねる（仮に 3 枚）→ つなぐ → 丸い穴（仮に深さ 70%）→ 平らに → 削る（5%）→ 色
- 絵：`amadare-top.png`・`amadare-section.png`（案 1）、`amadare-v2-top.png`・`amadare-v2-section.png`（案 2）
- 正直なところ：**案 1 と案 2 の絵が、ほとんど同じ**。案 1 で Claude が枚数を仮に 9 枚（3 種を 3 回くり返し）にしたので、浅い穴（25%）でも 3 枚目の銅に届き、赤が出てしまった。試した結果（浅いと赤が出ない）とは合わない。絵は「仮」の値しだいで大きく変わる。穴はきれいに同じ間に並びすぎている（錐で手であけた穴のばらつきは無い）。断面のとがった形は、厚みを縦にのばして描いているので強く見える。

### 2. 霞刃の小刀（kasumi）— 2 種の鋼を重ね直し、溝を刻んで叩く

- 手がかり：刃の表に灰色と白の細い線、ところどころ刃を横切る帯（はしごの段）／折れた先に数えきれない層／覚え書き「黒き鉄と白き鉄を重ね、幾度も折り返す。のち溝を刻み、打ち延べ、研ぎて酸に浸す」／年寄りの話「溝は鏨で横に刻んでから、平らに叩きつぶしていた」
- 案（10 手順）：鉄を選ぶ → 重ねて熱し一つに → 何度も折り返す → 焼きなまし（帳面から）→ 鏨で横に溝 → 平らに叩きつぶして打ち延べ → 小刀の形（もともと）→ 焼き入れ・焼き戻し（もともと）→ 研ぐ → 酸に浸す
- 操作：重ねる（黒くなる鋼・白く残る鋼を仮に 7 枚）→ つなぐ → 重ね直し 4 回（16 倍）→ まっすぐな溝（仮に深さ 30%・10 本）→ 平らに → のばす（1/2）→ 削る（5%）→ 酸で地を出す
- 絵：`kasumi-top.png`・`kasumi-section.png`
- 正直なところ：はしごの帯は出た。ただ、帯の中の線は画素より細かく、絵ではざらついた縞に見える。帯と帯の間は、まだらの大きな模様になり、本物の刃に多い流れる細い線には見えない（刃を斜めに研ぐことは、この計算ではできない）。

### 3. 渦金の帯留め（uzu）— 重ねた棒をねじり、平たくして深く削る

- 手がかり：表に星のような渦が長い向きに一定の間で並ぶ／端の切り口で層がななめに回る／弟子の話「熱した四角い棒の片方を万力で挟み、もう片方を回した。叩いて平たくし、砥石で深く削った」／書きつけ「重ねて棒となし、ねじりて後、打ち平め、深く磨く」
- 案（10 手順）：金属を用意 → 交互に重ねる → 一つにつなぎ棒に → 四角い棒にととのえる → 赤くなるまで熱する → 万力でねじる → 叩いて平たく → 焼きなまし（帳面から）→ 砥石で深く削る → 帯留めの形・金具（もともと）
- 操作：重ねる（鉄・明るい色の材料を仮に 16 枚）→ つなぐ → ねじる（仮に 3 回）→ 平らに → 削る（仮に 30%）
- 絵：`uzu-top.png`・`uzu-section.png`
- 正直なところ：回る縞は出たが、「星」には見えず、木の目のような流れに近い。四角い棒のねじれを、角を折り返す近似で描いているため。手順に色を出す工程が無いので、計算が「材料そのものの色で描いた。色の差は小さい」と知らせ、絵は灰色っぽい（Claude は工程にない色出しを足さなかった。これは正しい）。

### 4. 市松縞の小箱（ichimatsu）— 縞の板を立てて、四角に切って互い違いに並べる

- 手がかり：ふたに縦の縞と横の縞の四角が交互に並ぶ市松／縁の切り口で層が表に向かって立つ／書きつけ「縞の板を立てて重ね、賽の目に切り、互い違いに据えて継ぐ」／見立て「さかいは、ろうでなく熱して一つにしたように見える」
- 案（9 手順）：黒と白の材料 → 重ねて縞の塊 → ゆっくり冷ます（帳面から）→ 縞が立つ向きに切り出す → 賽の目に切る → 互い違いに並べる → 熱で継ぐ → ゆっくり冷ます（帳面から）→ ふたに仕立てる（もともと）
- 操作：重ねる（暗い色・明るい色を仮に 12 枚）→ つなぐ → 横にして層のふちを表に → 四角に切って 1 つおきに回す（仮に 6）→ つなぐ → 平らに → 削る（3%）→ 色は出さない
- 絵：`ichimatsu-top.png`・`ichimatsu-section.png`
- 正直なところ：縦と横の縞が互い違いの市松は出た。ただ、12 枚を 6 つに切ったので、1 つの四角に縞が 2 本ほどしかなく、太い。叩いて平らにする時のゆらぎで、四角のさかいが少し波打つ。

### 5. 月影留め（tsukikage）— 断るのが正しい技

- 手がかり：銀の指輪に乳白色の丸い石、地から彫り起こした小さな爪で留める／書きつけ「鏨にて地を起こし、石を伏せて爪を倒す」／見立て「石の下に光を返す細かな線」
- 案（10 手順）：銀の地 → 焼きなまし（帳面から）→ しるす → 座を彫る → 石の下に線（帳面から：線の幅と深さ・細い溝は手で彫る）→ 鏨で爪を起こす → 爪の太さ（帳面から：爪の最低の太さ）→ 石をふせる → 爪を倒す → 仕上げ（もともと）
- `predict_pattern` の答え：**描かない**。「銀ひとつの地から爪を彫り起こして石を留める技で、色のちがう材料を重ねて模様を出す技ではないため。石の下の細い線も、一枚の地に線を彫るだけなので合いません。」— 無理に模様にしなかった。画面には絵の代わりに、この理由を出す。

## この計算でできないこと（職人に伝えること）

- 形だけの見込み。金属の本当の流れ・熱・割れ・溶けは計算しない。色は絵の色（仮）で、本当の色あいではない。
- 数（枚数・深さ・回数）は Claude が絵のために仮に決める。同じ手順でも、仮の値で絵は大きく変わる（雨垂れ銀の案 1 と案 2）。
- 刃を斜めに研ぐ、品物の形に曲げる、象嵌のように別の物を埋める、は描けない。四角い棒のねじれは近似。
- 層の数がとても多いと、画素より細かくなり、ざらついて見える。
- 重ねた層の模様の技でなければ、描かずにそう言う（月影留め）。
