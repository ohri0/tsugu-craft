# 渦金の帯留め（uzu）

## 案 1
黒い鉄と白い金属を交互に重ねて四角い棒にし、赤くなるまで熱してねじり、叩いて平たくしてから表を深く削ると、星のような渦が出るのではないかという案です。古い書きつけと弟子の話がよく合っているので流れは強く言えそうですが、白い金属が何か、どうつないだか、数や温度はまだ分かりません。
1. 黒い金属と白い金属を用意する
2. 交互に重ねる
3. 重ねた板を一つにつなぎ、棒にする
4. 四角い棒の形にととのえる
5. 赤くなるまで熱する
6. 片方を万力で挟み、もう片方を回してねじる
7. 叩いて平たくする
8. 途中で焼きなまし、ゆっくり冷ます［帳面：焼きなましたら、ゆっくり冷ます・焼きなましたら、ゆっくり冷ます］
9. 表を砥石で深く削る
10. 帯留めの形に切り、金具をつける［もともとの知識］

### 模様の見込み（案 1）：描く
黒い鉄と白い金属を重ねてねじり、平たくして削る流れを、重ねる・つなぐ・ねじる・平らにする・削るの操作に置きかえました。
ねじれた層を深く削るので、表に黒と白の線が渦や星のように回る模様が出るかもしれません。ただし枚数・ねじる回数・削る深さは仮の値なので、見え方は変わりそうです。
- stack（工程 2）鉄・明るい色の材料を 16 枚、順に重ねる　仮：白い金属は名前が分からないので明るい色の材料にしました。黒い金属は鉄にしました。枚数は絵のために仮に16枚にしました。
- bond（工程 3）熱してつなぐ（よくつながる）　仮：つなぎ方は分からないので、絵ではよくつながったことにしました。
- twist（工程 6）ねじる（3 回）　仮：ねじる回数は分からないので、絵のために仮に棒の長さの中で3回にしました。
- flatten（工程 7）叩いて平らにする
- grind（工程 9）表を削る（厚みの 30%）　仮：深さは分からないので、絵のために仮に厚みの0.3にしました。
表せないこと：赤くなるまで熱したときの色と温度、四角い棒にととのえるときの太さ、途中の焼きなましとゆっくり冷ますこと、帯留めの形に切ることと裏の金具は、この絵では表せません。
計算の知らせ：最後に色を出す手順が無いので、材料そのものの色で描きました。色の差は小さく見えます。
