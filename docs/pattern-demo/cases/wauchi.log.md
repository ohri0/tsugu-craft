# 輪打ち金筋（wauchi）

## 案 1
古い覚え書きをもとにすると、赤銅の板に波の筋を彫って金を打ち込み、平らにしてから、輪の鏨で地を打ちつめ、最後に煮て黒くした、という順番が考えられる。輪の大きさ、筋の数、煮る液、赤銅の中身は手がかりになく、試して決める所が多い案です。
1. 赤銅の板を用意する
2. 板を焼きなまして、ゆっくり冷ます［帳面：焼きなましたら、ゆっくり冷ます・焼きなましたら、ゆっくり冷ます］
3. 波の筋の下絵を描く
4. 筋の溝を彫る［帳面：彫りの深さ］
5. 溝に金を伏せる
6. 金を打ち込んで平らにする
7. 輪の鏨を用意する
8. 輪の鏨で地を打ちつめる
9. 煮る前に汚れと油を落とす［もともとの知識］
10. 煮て地を黒くする

### 模様の見込み（案 1・絵 wauchi）：描く
1枚の赤銅の板に飾りをつける技なので、板の飾りの計算にした。金の筋は象嵌、輪の打ちつめは魚々子、煮て黒くするのは色出しにした。
黒い地に小さな輪が列になってびっしり並び、その中を金の細い筋が何本か、波のようにゆるく流れる見た目になりそうです。
- plate（工程 1）赤銅の板を 1 枚用意する
- zogan（工程 4）金を波の線ではめる（象嵌）　仮：筋の数は5本、線の半分の幅は板の幅の0.01と、絵のために仮に決めた。覚え書きに数が無いため
- nanako（工程 8）魚々子の輪を列に打つ（幅の中に 30）　仮：輪の半径は板の幅の0.012（けしの実ほどの小ささのつもり）、幅の中に30個並ぶと仮に決めた
- color（工程 10）色を出す：薬で色を出す（煮色のように）
表せないこと：焼きなましとゆっくり冷ますこと、下絵を描くこと、鏨を作ること、汚れを落とすことは絵に出ない。品物の本当の波の形は描けず、近い波の線にした。金の筋の上も輪を打ったのか、筋をよけたのかは分からないが、計算ではどちらかに決めて描かれる。溝の深さや底を広げた形、煮る液による本当の黒さ、地のざらりとした光り方も表せない。
