# 雨垂れ銀（amadare）

## 案 1
古い覚え書きから考えると、赤銅・銀・銅を重ねて火で一つにし、表から浅く穴を彫って打ち平らにし、最後に煮て色を揚げた技かもしれません。目の黒・白・赤の輪は、穴の深さで出る層の数が変わってできたものと考えられますが、深さ、重ねる順番、温度、煮る液はまだ分かりません。これは試して確かめるための案です。
1. 三つの地金を用意する
2. 重ねる面をきれいにする［もともとの知識］
3. 重ねて火で一つにする
4. 焼きなましてゆっくり冷ます［帳面：焼きなましたら、ゆっくり冷ます］
5. 表から浅く穴を彫る
6. 打って平らにする
7. 表と裏をととのえる
8. 煮て色を揚げる

### 模様の見込み（案 1）：描く
赤銅・銀・銅を重ねてつなぎ、表から浅く穴を彫って打ち平らにし、煮て色を出す手順を、そのまま操作に置きかえました。
黒い地に、穴の所だけ白と赤の輪がのぞく、同じ間に並んだ目の模様になるかもしれません。ただし表を削らないので、輪がはっきり出ないことも考えられます。
- stack（工程 1）赤銅・銀・銅を 9 枚、順に重ねる　仮：重ねる順番と枚数が分からないので、上から赤銅・銀・銅を3回くり返して9枚とした。絵のための仮の値
- bond（工程 3）熱してつなぐ（よくつながる）　仮：温度や時間が分からないので、よくつながったと仮に決めた
- carve（工程 5）表から彫る：決まった間の丸い穴（深さは厚みの 25%）　仮：深さと間が分からないので、深さは厚みの4分の1ほどで上から3枚目の銅に届くくらい、幅に8つ並ぶ、穴の半径は幅の0.03とした。絵のための仮の値
- flatten（工程 6）叩いて平らにする
- color（工程 8）色を出す：薬で色を出す（煮色のように）　仮：煮る液が分からないので、煮色のような色の出方として描く
表せないこと：焼きなましとゆっくり冷ますことは、模様の形を変えないので描いていません。表と裏をととのえる工程は、削ったのか、磨いただけか、何もしなかったのかが分からないので、削る操作は入れていません。削ると見える輪の数が変わるかもしれません。煮る液による本当の色の深さ、熱しすぎて溶けること、表に残る打ち跡は表せません。

試した結果（表から浅く穴を彫る）：ng　【架空】小さな切れ端で試した。浅い穴では、黒と白の輪しか出ず、赤い輪が出なかった。もう少し深くあけた所だけ、赤い輪が出た。

## 案 2
古い覚え書きと職人の試しから、赤銅・銀・銅を重ねて火で一つにし、表から銅の層まで届く深さで穴をあけ、打ち平らにして煮て色を揚げた技かもしれない、と考えました。浅い穴では赤い輪が出なかったので、覚え書きの「浅く」は、裏まで抜けない程度の意味かもしれません。深さ、重ねる順、温度、煮る液はまだ分からないので、試して確かめるための案です。
1. 三つの地金を用意し、重ねる順の見当をつける
2. 重ねる面をきれいにする［もともとの知識］
3. 重ねて火で一つにする
4. 焼きなましてゆっくり冷ます［帳面：焼きなましたら、ゆっくり冷ます・焼きなましたら、ゆっくり冷ます］
5. 表から、銅の層まで届く深さで穴をあける
6. 打って平らにする
7. 表と裏をととのえる
8. 煮て色を揚げる

### 模様の見込み（案 2）：描く
赤銅・銀・銅の三枚重ねに、銅の層まで届く穴をあけ、打ち平らにして煮色を揚げる操作に置きかえました。
黒い赤銅の地に、同じ間で並ぶ丸い目が出て、目の中に白い銀の輪と、真ん中に赤い銅の色がのぞくかもしれません。穴の深さが銅に届かないところでは、赤が出ないことも考えられます。
- stack（工程 1）赤銅・銀・銅を 3 枚、順に重ねる　仮：各一枚ずつで三枚、厚さは同じと仮に決めた。重ねる順と厚さはまだ推し量り
- bond（工程 3）熱してつなぐ（よくつながる）　仮：温度や時間は分からないので、よくつながったとして描く
- carve（工程 5）表から彫る：決まった間の丸い穴（深さは厚みの 70%）　仮：三枚が同じ厚さなら銅は厚みの三分の二より下なので、深さを厚みの0.7とした。穴の大きさと並ぶ数も仮
- flatten（工程 6）叩いて平らにする
- grind（工程 7）表を削る（厚みの 5%）　仮：削るか磨くかは分からないので、ごく浅く厚みの0.05とした
- color（工程 8）色を出す：薬で色を出す（煮色のように）　仮：煮る液は分からないので、煮色として描く
表せないこと：焼きなましとゆっくり冷ますこと、面の汚れ落とし、火の温度、裏に響くかどうか、煮る液による本当の色あい
