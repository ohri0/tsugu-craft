# 雨垂れ銀（amadare）

## 案 1
古い覚え書きをもとにした案です。赤銅・銀・銅を重ねて火で一つにし、錐で浅い穴をあけて打ち平め、最後に煮て色を出すと、黒・白・赤の輪の目になると考えられます。重ねる順、穴の深さと間、熱し方、色揚げの液は手がかりになく、試して決める所です。
1. 三つの地金の板を用意する
2. 重ねる面をきれいにする［もともとの知識］
3. 三枚を重ねる
4. 火で一つにする
5. 熱したあと、ゆっくり冷ます［帳面：焼きなましたら、ゆっくり冷ます・焼きなましたら、ゆっくり冷ます］
6. 錐で浅い穴をあける
7. 打って平らにする
8. 裏を平らに仕上げる
9. 表を整える［もともとの知識］
10. 煮て色を出す

### 模様の見込み（案 1・絵 amadare-first）：描く
赤銅・銀・銅を重ねてつなぎ、表から浅い穴をあけて打ち平め、煮色で色を出す流れに置きかえました。
黒い赤銅の地に、穴の所で白い銀がのぞく、黒と白の目が並ぶ絵になりそうです。打ち平めたときに穴がふさがって、模様がうすくなるかもしれません。仮に決めた浅い穴では銅まで届かないので、赤い芯は出ないと思われます。
- stack（工程 1）赤銅・銀・銅を 3 枚、順に重ねる　仮：上から赤銅・銀・銅の順で、同じ厚さの三枚と仮に決めた。覚え書きに書かれた順を、そのまま上からの順として使った。重ねる順と厚さは分かっていない。
- bond（工程 4）熱してつなぐ（よくつながる）　仮：よくつながると仮に決めた。熱し方は分かっていない。
- carve（工程 6）表から彫る：決まった間の丸い穴（深さは厚みの 40%）　仮：深さは厚みの0.4、穴の半径は幅の0.04、幅の中に8つと仮に決めた。浅いと書かれているので、この深さでは銀の層までしか届かず、まん中に銅の赤は出ない絵になる。
- flatten（工程 7）叩いて平らにする
- grind（工程 9）表を削る（厚みの 1%）　仮：磨くだけなので、深さは厚みの0.01と仮に決めた。
- color（工程 10）色を出す：薬で色を出す（煮色のように）
表せないこと：裏を平らに仕上げる所（裏の削りや打った跡）、熱の加減、ゆっくり冷ますことの効き目、煮る液の種類と色の深さ、錐の先の形。

試した結果（錐で浅い穴をあける）：ng　【架空】小さな切れ端で試した。浅い穴では、黒と白の輪しか出ず、赤い輪が出なかった。もう少し深くあけた所だけ、赤い輪が出た。

### 模様の見込み（案 1・絵 amadare）：描く
赤銅・銀・銅を重ねてつなぎ、表から浅い穴をあけ、打ち平めて煮色を出す流れに置きかえました。
黒い地に、白い輪で囲まれた目が同じ間で並ぶ見込みです。穴が浅いので、目の真ん中に赤は出ず、黒と白の二色の目になりそうです。
- stack（工程 1）赤銅・銀・銅を 3 枚、順に重ねる　仮：上から赤銅・銀・銅の順で、厚さは同じとした。試した結果で浅い穴に黒と白しか出ず、深い所だけ赤が出たので、黒がいちばん上、赤がいちばん下と考えた
- bond（工程 4）熱してつなぐ（よくつながる）　仮：熱し方は分からないので、よくつながったとして描く
- carve（工程 6）表から彫る：決まった間の丸い穴（深さは厚みの 50%）　仮：深さは厚みの半分とした。三枚が同じ厚さなら、銀の層までは届いて銅の層には届かない。試した結果の、浅い穴では赤い輪が出なかったことに合わせた。穴の大きさと数も仮の値
- flatten（工程 7）叩いて平らにする　仮：表から打ったとした
- grind（工程 9）表を削る（厚みの 2%）　仮：磨くだけなので、ごく浅く削るとした
- color（工程 10）色を出す：薬で色を出す（煮色のように）　仮：液の種類は分からないので、赤銅が黒く、銀が白く、銅が赤く見えるとして描く
表せないこと：熱したあとにゆっくり冷ますこと、裏を平らに仕上げること（この絵は表と断面だけ）、熱の加減、色揚げの液、磨いた手ざわりは表せません。

## 案 2
古い覚え書きと職人の試しをもとにした案です。表から赤銅・銀・銅の順に重ねて火で一つにし、錐で銅の層に届くが裏には抜けない深さまで穴をあけ、打ち平めてから煮て色を出すと、黒・白・赤の輪の目になると考えられます。穴の深さ、層の厚さ、熱し方、色揚げの液は試して決める所です。
1. 三つの地金の板を用意する
2. 重ねる面をきれいにする［もともとの知識］
3. 表から赤銅・銀・銅の順に重ねる
4. 火で一つにする
5. 熱したあと、ゆっくり冷ます［帳面：焼きなましたら、ゆっくり冷ます・焼きなましたら、ゆっくり冷ます］
6. 錐で、銅の層に届く深さまで穴をあける
7. 打って平らにする
8. 裏を平らに仕上げる
9. 表を整える［もともとの知識］
10. 煮て色を出す

### 模様の見込み（案 2・絵 amadare-v2）：描く
三つの地金を重ねてつなぎ、穴をあけて打ち平め、煮て色を出す流れを、そのまま操作に置きかえました。前の案と変えたのは、穴の深さだけです。
穴が銅の層まで届くので、表には黒い地の中に白い輪と赤い芯の目が、同じ間で並ぶ見込みです。ただし三枚が同じ厚さという仮の値によるもので、本当の厚さによって赤の出方が変わるかもしれません。
- stack（工程 3）赤銅・銀・銅を 3 枚、順に重ねる　仮：前の案と同じく、三枚とも同じ厚さとした。厚さは分からないので、絵のための仮の値
- bond（工程 4）熱してつなぐ（よくつながる）　仮：前の案と同じく、よくつながったとした。面をきれいにする工程とゆっくり冷ます工程は、つながり方の仮の値に含めた
- carve（工程 6）表から彫る：決まった間の丸い穴（深さは厚みの 70%）　仮：三枚が同じ厚さなら、銅の層は表から厚みの約三分の二の所から始まる。それより少し深い、厚みの70%とした。浅い穴では赤が出ず、深い所だけ赤が出たという試した結果に合わせた。前の案（50%）から変えたのは深さだけで、穴の大きさと数は前と同じ
- flatten（工程 7）叩いて平らにする　仮：前の案と同じく、表から打ったとした
- grind（工程 9）表を削る（厚みの 2%）　仮：前の案と同じく、厚みの2%とした
- color（工程 10）色を出す：薬で色を出す（煮色のように）　仮：液は分からないので、前の案と同じく、赤銅が黒く、銀が白く、銅が赤く見えるとして描いた
表せないこと：重ねる面のきれいさ、ゆっくり冷ますことの効き目、裏を平らに仕上げること（この絵は表の削りしか描けません）、熱する温度、煮る液や色の具合は、この絵では表せません。
