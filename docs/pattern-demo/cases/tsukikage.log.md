# 月影留め（tsukikage）

## 案 1
月影留めは、銀の地を鏨で起こして小さな爪を作り、石を伏せて爪を倒して留める技かもしれない、という案です。古い書きつけと残った指輪から、この順番はある程度言えます。しかし、爪の数や太さ、焼きなましの有無、石の下の線があるかどうかは、試して確かめる必要があります。
1. 銀の地を用意する
2. 地を焼きなまして、ゆっくり冷ます［帳面：焼きなましたら、ゆっくり冷ます・焼きなましたら、ゆっくり冷ます］
3. 石の場所と爪の場所に印をつける［もともとの知識］
4. 石の下に細い線を彫る［帳面：彫りの深さ・細い溝は、あとから手で彫る］
5. 鏨で地を起こして爪を作る［帳面：爪の最低の太さ（石の大きさで）］
6. 石を伏せる
7. 爪を倒して石を留める
8. 爪の先と地を仕上げる［もともとの知識］

### 模様の見込み（案 1・絵 tsukikage）：描かない
石を留める技で、地を起こして爪を作り、石を伏せて倒す工程が中心です。まわりの地に彫りや打ちの飾りはありません。石の下の細い線は、あるかどうかが見立てにとどまり、あっても石の下にかくれます。重ねた層の模様にも、板の表の飾りにも合わないので、絵にしませんでした。
見込みですが、仕上がりは銀の地に小さな爪で乳白色の石を留めた見た目になりそうです。表に模様が出る工程はなさそうなので、模様の絵は出しません。
表せないこと：地から起こした爪の形と数、乳白色の丸い石とその置き方、爪を倒して石を押さえるようす、石の下の細い線（あるかどうか分からず、あっても石の下にかくれる）、焼きなましとゆっくり冷ますこと、指輪の形、仕上げの磨き。
