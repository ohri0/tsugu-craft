# 月影留め（tsukikage）

## 案 1
月影留めは、銀の指輪の地を鏨で起こして爪を立て、石をふせてから爪を倒して留める技かもしれない、という案です。石の下には、光を返す細かな線が彫ってあったかもしれません。数字や順番の多くはまだ分からないので、小さな切れ端で試して決める必要があります。
1. 銀の指輪の地を用意する
2. 彫る前に地をやわらかくする（焼きなまし）［帳面：焼きなましたら、ゆっくり冷ます・焼きなましたら、ゆっくり冷ます］
3. 石の位置と爪の位置をしるす
4. 石をふせる座を彫る
5. 石の下に細かな線を彫る［帳面：線の幅と深さ・細い溝は、あとから手で彫る］
6. 鏨で地を起こして爪を立てる
7. 爪の太さと形を整える［帳面：爪の最低の太さ（石の大きさで）］
8. 石を座にふせる
9. 爪を倒して石を留める
10. 爪の先と全体を仕上げる［もともとの知識］

### 模様の見込み（案 1）：描かない
銀ひとつの地から爪を彫り起こして石を留める技で、色のちがう材料を重ねて模様を出す技ではないため。石の下の細い線も、一枚の地に線を彫るだけなので合いません。
重ねた層の模様が出る技ではなさそうなので、この計算では絵にしません。
表せないこと：爪を起こして石を留める形、石をふせる座、石の下の細い線の光り方、乳白色の石、指輪の形、仕上げの磨き
