# 粒金槌目の留め具（tsubukin）

## 案 1
金の板を丸い槌で打って一面に浅いくぼみをつけ、そのあと小さな金の粒を七つほど寄せて花の房にし、火で留めたという案です。粒のまわりにろうのたまりが見えないので、熱だけで留めたのかもしれませんが、まだ推し量りの段階です。
1. 金の板を用意する
2. 焼きなまして、ゆっくり冷ます［帳面：焼きなましたら、ゆっくり冷ます］
3. 丸い槌で表を打つ
4. 小さな金の粒を作る［もともとの知識］
5. 粒を寄せて花の房にする
6. 火で粒を留める
7. 留めたあと、ゆっくり冷ます［帳面：ロウ付けのあとは、ゆっくり冷ます・ロウ付けのあとは、ゆっくり冷ます］
8. 留め具の形に仕上げる［もともとの知識］

### 模様の見込み（案 1・絵 tsubukin）：描く
1枚の金の板の表に、槌目をつけて粒金の房をのせる技なので、板の表の飾りとして置きかえました。
金の地の一面に、光を細かくはね返す浅い丸い槌目が広がり、その上に小さな金の粒の房がほぼ同じ間で並ぶ見た目になりそうです。地も粒も同じ金なので、色の差は出ず、凹凸と光の当たり方だけで模様が見える見込みです。
- plate（工程 1）金の板を 1 枚用意する　仮：金の混ぜ物や純度が分からないので、ふつうの金の色で描く。
- tsuchime（工程 3）金槌の丸い跡をつける　仮：くぼみは小さく浅く重なり合うとあるので、深さを厚みの0.08、跡の半径を板の幅の0.03と仮に決めた。
- granulate（工程 5）金の粒を房にしてつける　仮：粒はけしの実より小さいので、半径を板の幅の0.012と仮に決めた。房が板の幅に並ぶ数は書かれていないので、3つと仮に決めた。
表せないこと：焼きなましやゆっくり冷ますこと、熱の色は描けません。粒の作り方は描けません。ろうを使わず熱だけで留めたのか、ろうを使ったのかのちがいも描けません。七つの粒が作る花の本当の形は描けず、近い房の形にしています。留め具の形に切ったり曲げたりすることも描けません。
