# 霞刃の小刀（kasumi）

## 案 1
霞刃の小刀は、色の違う二種類の鉄を重ねて何度も折り返し、横に溝を刻んでから平らに叩きつぶし、研いで酸に浸して線を出したものかもしれない。鍛冶の覚え書きと年寄りの話が大すじを支えているが、材料、回数、温度、酸の種類はどれも分からない。焼き入れと形を作る工程は、手がかりにはなく、もともとの知識から足した案である。
1. 色の違う二種類の鉄を選ぶ
2. 重ねて熱し、叩いて一つにくっつける
3. 何度も折り返して層を増やす
4. 溝を刻む前に焼きなまし、ゆっくり冷ます［帳面：焼きなましたら、ゆっくり冷ます・焼きなましたら、ゆっくり冷ます］
5. 鏨で横に溝を刻む
6. 平らに叩きつぶして打ち延べる
7. 小刀の形にする［もともとの知識］
8. 焼き入れと焼き戻し［もともとの知識］
9. 研ぐ
10. 酸に浸して線を出す

### 模様の見込み（案 1）：描く
黒い鉄と白い鉄を重ねて折り返し、横の溝を彫ってから叩きつぶし、研いで酸で色を出す流れに置きかえた。
細かい灰色と白の線の中に、溝の所で線が詰まった帯が刃を横切って並び、はしごの段のような模様になるかもしれない。
- stack（工程 1）黒くなる鋼・白く残る鋼を 7 枚、順に重ねる　仮：鉄の種類は分からないので、酸で黒くなる鋼と白く残る鋼にした。枚数は分からないので、絵のために仮に7枚とした
- bond（工程 2）熱してつなぐ（よくつながる）　仮：くっつき具合は分からないので、よくつながるとした
- fold（工程 3）のばして切り、重ねる（4 回。層が 16 倍）　仮：回数は分からないので、表に何十本も線が出るよう仮に4回とした
- carve（工程 5）表から彫る：まっすぐな溝（深さは厚みの 30%）　仮：深さ、幅、間かくは分からないので、仮に深さを厚みの3割、溝の半分の幅を0.02、10本とした
- flatten（工程 6）叩いて平らにする
- forge_thin（工程 6）叩いて厚みを 1/2 に（長さの向きにのばす）　仮：どれだけ延ばすかは分からないので、仮に厚みを2分の1とした
- grind（工程 9）表を削る（厚みの 5%）　仮：研ぐ深さは分からないので、仮に厚みの5分
- color（工程 10）色を出す：酸などで地を出す
表せないこと：溝の前の焼きなましとゆっくり冷ますこと、小刀の形にすること、焼き入れと焼き戻し、熱の温度、酸の種類と濃さはこの絵では表せない。
