# 花透かしの縁彫り板（sukashibori）

## 案 1
銀の板に花の形を割り付けて切り抜き、ふちに毛彫りで二本の線を、花の間の地に片切彫りで草のような線を散らした、という案です。彫りの種類は品物と古い書きつけからかなり言えますが、切り抜きの道具、順番、板の厚さなどはまだ分からず、試して確かめる必要があります。
1. 銀の板を用意する
2. 板をなます（やわらかくする）［帳面：焼きなましたら、ゆっくり冷ます・焼きなましたら、ゆっくり冷ます］
3. 花の位置を割り付ける
4. 花を透かす（切り抜く）
5. 切り口をととのえる［もともとの知識］
6. 板を動かないように留める［もともとの知識］
7. ふちに毛彫りで二本の線［帳面：彫りの深さ］
8. 地に片切彫りで草を散らす［帳面：彫りの深さ］
9. 仕上げ［もともとの知識］

### 模様の見込み（案 1・絵 sukashibori）：描く
1枚の銀の板の表を飾る技なので、板の飾りの計算にしました。描ける工程は、銀の板、花の透かし、ふちの毛彫り、地の片切彫り、仕上げです。
銀の地に五弁の花の穴が同じ間で並び、ふちを細い毛彫りの線2本が囲み、花の間に片側だけ光る短い線が散らばる見た目になりそうです。
- plate（工程 1）銀の板を 1 枚用意する
- sukashi（工程 4）花びらの形を切り抜く（幅の中に 4）　仮：花の大きさを板の幅の0.08くらい、幅の中に4つ並ぶと絵のために仮に決めた。割り付けた花はほぼ同じ間で並ぶので、間はそろえて描く
- kebori（工程 7）毛彫りで、ふちにそった枠を彫る（2 本・深さは厚みの 20%）　仮：板の厚みを1mmくらいと仮に決め、工房の目安のまん中0.2mmから深さを厚みの0.2にした。線の半分の幅は0.005にした
- katakiri（工程 8）片切彫りで、散らした短い線を彫る（12 本・深さは厚みの 20%）　仮：深さは毛彫りと同じ厚みの0.2、線の半分の幅を0.01、幅の中に12本くらいと絵のために仮に決めた
- color（工程 9）色を出す：出さない　仮：磨きか色つけかは分からないため、色をつけない形で描いた
表せないこと：板をなますこと、花の割り付けの描き方、切り抜きの道具（糸鋸か鏨か型か）と切り口の跡、切り口をととのえるか、板を留めること、磨いた光り方は描けません。草の葉の本当の形と向きは、短い線を散らす形でしか表せません。板の厚さと銀の質も表せません。
計算の知らせ：透かした所は、後ろの暗い地が見えるとして描きました。
