# ダマスカス鋼（ウーツ鋼）の模様（wootz・職人の帳面あり（2026-11-08 の言葉も））

## 案 1
炭素の多い鋼の塊を坩堝で作り、温度をおさえて少しずつ叩きのばし、研いで液で色の差を出す、という流れの案です。手がかりからは、模様は塊の中のむらが平たくなった帯から出ると考えられますが、帯のでき方や熱のくり返し方はまだはっきりしません。職人の目で見た「折って叩く」道とは作り方がちがうかもしれないので、見比べて確かめることをすすめます。
1. 坩堝で炭素の多い塊を作る
   鉄と木炭と植物を坩堝（るつぼ）に入れて長く熱し、炭素の多い鋼の塊（ウーツ）を作る、と考えられる。手がかりの「材料の塊」では、模様の元はこの一つの塊で、板を重ねた物ではないとされる。
   分からない：鉄・木炭・植物の割合、植物の種類、何度で何時間熱するかは分からない。試して決める。
2. 塊をゆっくり固める
   塊が固まるとき、ごく少しの混じり物（バナジウムなど）が結晶の枝のすき間に集まってむらができ、これが模様の帯の元になる、という説がある。そのため、坩堝の中で固まらせ方を選んでいたのかもしれない。ただ、この説には疑問も出ている。
   分からない：冷ます速さ、混じり物がどれだけ要るか、鉱石によってちがうのかは分からない。
3. 温度を上げすぎずに鍛える［帳面：熱しすぎると模様がぼやける。切れ端で試す］
   手がかりの「熱」では、ある温度より上に長く置くと模様が消え、約 730 ℃ のすぐ上と下をくり返して炭化物の粒を育てる、とされる。この工房でも、木目金で、熱しすぎると模様がぼやけると判断している。この技でも同じように、温度をおさえて少しずつ鍛えるのかもしれない。
   分からない：くり返す回数、一回ごとの時間、温度の幅は分からない。小さな切れ端で試して決める。
4. 叩いてのばし、むらを平たくする［帳面：叩いてのばすと、中の物は平たくなる・薄くまでのばす］
   後の研究では、帯は刃の面にほぼ平行に並ぶ。この工房では木目金で、叩いてのばすと中のむらはのばした向きに平たく薄くなると判断しており、また板はだいぶ薄くまで打ちのばすと見ている。この技でも、塊を叩きのばすうちに、むらが面にそって平たい帯になるのかもしれない。
   分からない：どれだけ薄くのばすか、何回に分けるかは分からない。
5. はしごの段をつける（つける刃だけ）［帳面：彫ってから平らにすると、模様が彫りの形に寄る］
   手がかりの「はしごの段」では、刃を横切る段がほぼ同じ間で並び、段の所で地の模様が変わる。作り方は分かっていない。この工房では木目金で、表に溝を同じ間で彫ってから平らにすると、模様が同じ間でくり返すと判断している。この技でも、同じような方法だったかもしれない。
   分からない：彫るのか、押すのか、ほかの方法か分からない。溝の深さや間も分からない。
6. 刀の形に整え、刃に硬さを持たせる［もともとの知識］
   刀として使うには、形を整えたあと、刃を硬くする熱の処理をしたと考えられる。ただ、手がかりには書かれていない。もとから知っていることからの推し量り。
   分からない：熱の処理をしたかどうか、温度や冷まし方は分からない。高い温度に長く置くと模様が消えるとされるので、模様との関係も分からない。
7. 研いで面を出す［帳面：叩いてのばすと、中の物は平たくなる］
   手がかりの「刃の表の模様」では、模様は研いで仕上げた面に出る。研いで、帯を面で切り出すことで模様が見えると考えられる。
   分からない：どこまで研ぐか、研ぎの道具は分からない。
8. 色の差にして模様を見せる［帳面：模様は、色の差にして見せる］
   模様は、炭化物の粒の帯と鋼の地のちがい。この工房では木目金で、材料のちがいは磨くだけでは見えにくく、酸などで色の差にして見せると判断している。この技でも、明るい線と暗い地を出すために、液につけて色の差を出したのかもしれない。
   分からない：どの液を、どれだけ、何回つけるかは分からない。見本の切れ端で試して決める。

### 模様の見込み：描く
重ねない鋳た塊のむらを、叩きのばして研ぎ、液で色の差にする技なので、塊から始める重ねた層の模様に置きかえました。
黒い地に、白く明るい細い線が大きなうねりにそって流れ、ところどころ途切れて点で終わる模様になりそうです。はしごの段のところでは、ほぼ同じ間で模様が曲がって見えるかもしれません。
- ingot（工程 1）白く残る鋼・黒くなる鋼の、1 つの鋳た塊（中のむら：白く残る鋼が結晶の枝のすき間に濃くなる。幅の中に枝の間 30）　仮：網目の数を 30 にした。手がかりの線が細かく波打つので、大きなうねりの数よりずっと大きくした。
- forge_thin（工程 4）叩いて厚みを 1/8 に（長さの向きにのばす。打ちむらで層が厚みの 20% ほど上下にずれる。大きな打ち・曲げで、幅の中に 3 つほどの大きなふくらみ。熱して叩くのを 4 回くり返す（あとの回ほど小さな打ち））　仮：厚みを 8 分の 1、打ちむら 0.2、大きな打ち 3 つ、くり返し 4 回と仮に決めた。流れる水のような波打ちに近づけるため。
- carve（工程 5）表から彫る：まっすぐな溝（板全体に 40・深さは厚みの 20%）　仮：手がかりの段 40 から、品物全体で 40 本にした。溝の深さ 0.2、半分の幅 0.01 は仮。
- flatten（工程 5）叩いて平らにする（打ちむらで層が厚みの 15% ほど上下にずれる。大きな打ち・曲げで、幅の中に 3 つほどの大きなふくらみ）　仮：打ちむら 0.15、大きな打ち 3 つ、1 回と仮に決めた。溝の下の層がなだらかにたわむように。
- grind（工程 7）表を削る（厚みの 30%。面がうねり、深さが厚みの 5% ほど変わる（幅の中に 3 つほどのうねり））　仮：深さ 0.3、うねり 0.05、うねりの数 3 は仮。大きな打ちの数とそろえ、輪やうねりが出るように。
- color（工程 8）色を出す：酸などで地を出す　仮：濃淡 0.6 は仮。むらの濃さのとおりに間の色が続くように。
表せないこと：熱の温度とくり返し（約 730 ℃ の上下）、炭化物の粒が育つこと、熱しすぎて模様が消えること、刀の形に整えることと刃を硬くする熱の処理、研いだ面の光り方は描けません。帯が本当に枝のすき間のむらからできるかは分かっていないので、絵は説の形の仮の見込みです。
計算の知らせ：鋳た塊の中のむらは、「混じり物が結晶の枝のすき間に集まり、叩いてのばすと平たい帯になる」という説の形を、大きさのちがう枝が重なった、切れ目のない濃さのむらとして仮に描きました（幅の中に枝の間 30・仮）。むらの本当の形・量・並び方は分かっていません。 / 叩くときの打ちむら（1 回ずつの打ちで層が少し上下にずれる）は、跡の大きさ・数・深さを仮に決めて描きました。 / 熱して叩くくり返しは、2 回目からの打ちを、あとの回ほど小さく浅く、数を多くして、前の回の跡に重ねて描きました（小さくなる割合は仮。本当の回数と打ち方は分かっていません）。 / 大きな打ちと曲げ（金属を板の幅ほどの大きさで動かす）は、数・大きさ・ずれの深さを仮に決めて描きました。削ると、ふくらみの所に輪（目）が出ます。本当の打ち方は分かっていません。
