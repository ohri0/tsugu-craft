# ダマスカス鋼（ウーツ鋼）の模様（wootz・職人の帳面あり（2026-11-08 の言葉も））

## 案 1
一つの炭素の多い鋼の塊を作り、熱しすぎないよう、約730℃の上下をくり返しながら薄くまでのばし、研いで液で色を出すと模様が出るのではないか、という案です。重ねて打つかどうかは、職人の目と手がかりが分かれていて、試して確かめる所です。はしごの段の作り方や、帯ができるしくみは、まだ推し量りの段階です。
1. 坩堝で炭素の多い鋼の塊を作る
   鉄と木炭と植物を坩堝に入れ、長く熱して、炭素の多い鋼の塊にする。手がかり「材料の塊」に、こう書かれている。板を重ねた物ではなく、一つの塊から始めると考えられる。
   分からない：鉄・木炭・植物の割合、植物の種類、熱する温度と時間は分からない。試して決める。坩堝の土も分からない。
2. 塊をゆっくり固める
   手がかり「模様の正体」には、塊が固まるとき、ごく少しの混じり物が結晶の枝のすき間に集まり、それが帯の元になるという説がある。そうなら、固まり方で模様の元が決まるのかもしれない。ただし、この説には疑問も出ている。
   分からない：坩堝の中で冷ますのか、どれくらいの速さで冷ますのかは分からない。どんな混じり物がいるか（バナジウムなど）、それが材料の鉱石から来たのかも分からない。
3. 熱しすぎないように塊を鍛える［帳面：熱しすぎると模様がぼやける。切れ端で試す］
   手がかり「熱」には、ある温度より上に長く置くと模様が消える、とある。この工房でも、木目金について、熱しすぎると模様がぼやけたり消えたりすると判断している。この技でも、温度を上げすぎず、少しずつ打つのがよいかもしれない。
   分からない：どの温度より上がだめなのか、手がかりに書かれていない。一度にどれだけ打てるかも分からない。炭素の多い鋼は割れやすいかもしれないので、打ち方は試して決める。
4. 約730℃のすぐ上と下をくり返す
   手がかり「熱」に、粒を育てるには約730℃のすぐ上と下をくり返す、とある。鍛えながら、この温度の上下を行き来させると、炭化物の粒が帯に集まるのかもしれない。
   分からない：何回くり返すかは書かれていない。上と下でどれだけ置くか、温度をどう見分けるか（色で見るのか）も分からない。
5. 薄くまで打ちのばす［帳面：薄くまでのばす・叩いてのばすと、中の物は平たくなる］
   この工房では、叩いてのばすと中のむらはのばした向きに平たくなる、と判断している。手がかり「模様の正体」でも、帯は刃の面にほぼ平行に並ぶ。職人の目でも、板はだいぶ薄くまでのばす、としている。塊の中のむらを、のばして平たい帯にするのかもしれない。
   分からない：どこまで薄くするか、のばす向きをどう決めるかは分からない。
6. （分かれ目）塊を折り返して重ねるか［帳面：重ねて打ち込む］
   職人の目では、重ねて打ち込み、平らにしてまた重ねると模様が強く出る、と見ている。一方、手がかり「材料の塊」には、板を重ねて作った物ではない、とある。ちがう板を重ねるのではなく、一つの塊を折り返すことならありうるのか、それとも重ねずにのばすだけなのかは、ここが大きな分かれ目と考えられる。
   分からない：折り返すかどうか、折り返すなら何回かは分からない。重ねた模様と、塊の中のむらの模様が、表で見分けられるかも分からない。
7. （はしごの段があるとき）溝を同じ間で彫ってから平らにする［帳面：彫ってから平らにすると、模様が彫りの形に寄る］
   手がかり「はしごの段」では、段が刃を横切ってほぼ同じ間で並び、段の所で地の模様が変わる。この工房では、木目金について、表に溝を彫ってから叩いて平らにすると、模様が彫りの形に寄り、溝を同じ間で並べれば模様も同じ間でくり返す、と判断している。この技でも同じことが起きるのかもしれない。ただ、手がかりには、段の作り方は分かっていないとある。
   分からない：彫るのか、刃を横から打つのかなど、作り方は分からない。溝の深さと間も分からない。段は40と言われるが、実物はその前後とある。
8. 刃の形に整え、焼きを入れる［もともとの知識］
   刀なので、形を整えたあと、熱して冷やして硬くしたと考えられる。ただ、手がかりにも帳面にもない。
   分からない：焼きを入れたのか、どの温度から何で冷やしたのかは分からない。焼き入れで模様が消えないかも分からない。
9. 研いで仕上げる［帳面：叩いてのばすと、中の物は平たくなる］
   手がかり「刃の表の模様」では、模様は研いで仕上げた面に出る。この工房では、表の模様は平たくなった帯を表がどの深さで切ったかで決まる、と判断している。研ぐ深さで、とぎれとぎれの線や、点で終わる線が出るのかもしれない。
   分からない：どこまで研ぐか、どんな砥石を使うかは分からない。
10. 液につけて模様の色の差を出す［帳面：模様は、色の差にして見せる］
   手がかり「模様の正体」では、模様は炭化物の粒の帯と、鋼の地のちがい。この工房では、材料のちがいは磨いただけでは見えにくいので、酸などで色の差にして見せる、と判断している。この技でも、明るい線と暗い地を、液につけて出すのかもしれない。
   分からない：どの液を使うか、どれだけつけるかは分からない。見本の切れ端で試して決める。

### 模様の見込み：描く
重ねずに一つの鋳た塊から始める技なので、塊の中のむらから描き、のばす・段の溝・研ぐ・酸で色を出す、に置きかえました。
黒い地に、白く光る線が波打って流れ、ところどころでとぎれたり点で終わったりする模様になりそうです。長さの向きに、はしごのような段が 40 ほど、同じ間で並んで見えるかもしれません。
- ingot（工程 1）白く残る鋼・黒くなる鋼の、1 つの鋳た塊（中のむら：白く残る鋼が結晶の枝のすき間に濃くなる。幅の中に枝の間 12）　仮：網目の数を 12 と仮に決めた。炭化物の帯になるむらを明るい鋼、地を黒くなる鋼として描く
- forge_thin（工程 5）叩いて厚みを 1/8 に（長さの向きにのばす。打ちむらで層が厚みの 20% ほど上下にずれる。大きな打ち・曲げで、幅の中に 3 つほどの大きなふくらみ）　仮：厚みを 8 分の 1、打ちむら 0.2、大きな打ち 3 つと仮に決めた。流れる水のような波に近づけるため
- carve（工程 7）表から彫る：まっすぐな溝（板全体に 40・深さは厚みの 30%）　仮：手がかりの段の数から 40 本、深さ 0.3、溝の半分の幅 0.008 と仮に決めた
- flatten（工程 7）叩いて平らにする
- grind（工程 9）表を削る（厚みの 30%。面がうねり、深さが厚みの 10% ほど変わる（幅の中に 3 つほどのうねり））　仮：深さ 0.3、面のうねり 0.1、うねり 3 つと仮に決めた。線がとぎれて点で終わる所が出るように
- color（工程 10）色を出す：酸などで地を出す　仮：むらの濃さのとおりに間の色が続くよう、濃淡を 0.6 と仮に決めた
表せないこと：約730℃の上下をくり返して炭化物の粒が帯に集まることや、焼き入れ、熱しすぎて模様が消えることは描けません。重ねて打つかどうかの分かれ目は、手がかりの「重ねて作った物ではない」に合わせて、重ねない方だけを描いています。刃の形も描けません。
計算の知らせ：鋳た塊の中のむらは、「混じり物が結晶の枝のすき間に集まり、叩いてのばすと平たい帯になる」という説の形を、大きさのちがう枝が重なった、切れ目のない濃さのむらとして仮に描きました（幅の中に枝の間 12・仮）。むらの本当の形・量・並び方は分かっていません。 / 叩くときの打ちむら（1 回ずつの打ちで層が少し上下にずれる）は、跡の大きさ・数・深さを仮に決めて描きました。 / 大きな打ちと曲げ（金属を板の幅ほどの大きさで動かす）は、数・大きさ・ずれの深さを仮に決めて描きました。削ると、ふくらみの所に輪（目）が出ます。本当の打ち方は分かっていません。
