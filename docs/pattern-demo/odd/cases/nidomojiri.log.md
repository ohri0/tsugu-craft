# 二度捩り返し（nidomojiri）
考えた手順（Claude には渡さない）：2 種の鋼を重ねる → ねじる → 平らにする → 細く切り 1 本おきに返す → もう一度 2 本でねじる → のばす → 削る → 酸

## 案 1（47 秒）
鍛冶の覚え書きをもとに、黒い鉄と白い鉄を重ねて沸かし、ねじって平らにし、細く割って一つおきに返し、また沸かして二度目にねじり、延ばして研ぎ、酸で模様を出す流れの案です。「返す」と「二筋に捩じる」の意味がいちばん分かっていないので、まず粘土などの模型で読み方を比べるとよいと考えられます。
1. 黒い鉄と白い鉄を重ねる
   色の違う二つの鉄を交互に重ねる。鍛冶の覚え書きに「黒き鉄・白き鉄を重ね」とあり、小刀の地の黒と白の模様もこれから出ると考えられる。
   分からない：黒い鉄と白い鉄が何の鉄かは分からない。何枚重ねるか、厚さも分からない。試して決める。
2. 重ねて沸かしてつなぐ
   重ねた鉄を熱して叩き、一つの塊につなぐ（沸かし付け）。覚え書きに「重ね沸かし」とある。この工房では木目金で、熱しすぎると模様がぼやけると判断している。この技でも、どこまで熱してよいかは切れ端で試すのがよいかもしれない。
   分からない：何度まで熱するか、何をつけて沸かすかは分からない。試して決める。
3. 一度目の捩じり
   つないだ棒を熱して捩じる。覚え書きに「捩じりて」とあり、年寄りの話でも、まず一度ねじると読める。
   分からない：何回ねじるか、どの向きか、熱したままか分からない。
4. 打ち平める
   ねじった棒を叩いて平たくする。覚え書きに「打ち平め」とある。この工房の木目金の帳面では、叩くと中の層は平たくなり、表の模様は層をどの深さで切ったかで決まるとしている。この技でも、平たくする量で模様が変わるかもしれない。
   分からない：どこまで薄く平たくするか分からない。
5. 細く割る
   平たくした物を、細い棒に割る。覚え書きに「細く割りて」とある。
   分からない：何本に割るか、熱して割るか冷えて割るか分からない。
6. 一つおきに返す
   割った棒を、一つおきに向きを返して並べる。覚え書きに「一つおきに返し」、年寄りの話に「返してからもう一度ねじる」とある。返すことで、ねじりの向きが一つおきに逆になり、羽が交互に開いたり閉じたりする形になるのかもしれない。
   分からない：「返す」が裏表を返すのか、頭と尻を入れ替えるのか、ねじりの向きを逆にするのか分からない。
7. また沸かしてつなぐ
   並べ直した棒を、もう一度熱して叩いてつなぐ。覚え書きに「また沸かして」とある。二度目なので、熱しすぎで模様がぼやけないように気をつけるとよいかもしれない。
   分からない：熱の高さ、何度沸かすか分からない。
8. 二筋に捩じる
   もう一度ねじる。覚え書きに「二筋に捩じる」、年寄りの話に「もう一度ねじる」とある。これで羽の形が開くと考えられている。
   分からない：「二筋」が二本の棒をより合わせるのか、一本を二か所でねじるのか、逆向きに二度ねじるのか分からない。
9. 打ち延べる
   ねじった物を叩いて延ばし、刃の地にする。覚え書きに「打ち延べ」とある。叩いて延ばすと、中の模様も延ばした向きに平たくなると、この工房の木目金の帳面ではしている。
   分からない：どこまで延ばすか分からない。
10. 小刀の形にして、焼きを入れる［もともとの知識］
   小刀の形に整え、刃として使えるように熱の処理をすると考えられる。手がかりには書いていない。この工房では木目金で、焼きなましのあとはゆっくり冷ますと判断している。ただし刃を硬くする焼き入れは別のやり方かもしれない。
   分からない：焼き入れをしたのか、どう冷ましたのか、全く分からない。
11. 研ぐ
   刃と地を研いで、平らできれいな面にする。覚え書きに「研ぎて」とある。研ぐ深さで、表に出る層が変わるかもしれない。
   分からない：どの砥石でどこまで研ぐか分からない。
12. 酸に浸して模様を出す
   研いだ地を酸に浸して、黒と白の差を出す。覚え書きに「酸に浸す」とある。この工房でも、材料ごとの色の変わり方の違いで模様を見せ、液とつける長さは見本の切れ端で決めると判断している。
   分からない：どの酸か、濃さ、つける長さが分からない。試して決める。

### 模様の見込み（19 秒）：描く
黒い鉄と白い鉄を重ねてねじる技なので、重ねた層の模様として、重ねる・つなぐ・ねじる・平らにする・割って返す・またつなぐ・またねじる・延ばす・研ぐ・酸の順に置きかえました。
ねじりで出た星のような模様が、割って一つおきに返すことで向きの交互にかわる帯になり、二度目のねじりで、つなぎ目に羽が開いたような形が並ぶのではないかと見込まれます。延ばした向きに少し長くなりそうです。
- stack（工程 1）黒くなる鋼・白く残る鋼を 10 枚、順に重ねる　仮：黒い鉄は黒くなる鋼、白い鉄は白く残る鋼とした。枚数は10枚、同じ厚さと仮に決めた。
- bond（工程 2）熱してつなぐ（よくつながる）　仮：よくつながるとした。
- twist（工程 3）ねじる（3 回）　仮：1本の棒を、長さの中で3回ねじると仮に決めた。
- flatten（工程 4）叩いて平らにする
- rearrange（工程 5）切って並べかえる：細く切って 1 本おきに向きを変える　仮：4本に割るとした。返すは向きを入れ替える読み方で描いた。
- bond（工程 7）熱してつなぐ（よくつながる）　仮：よくつながるとした。
- twist（工程 8）ねじる（2 回）。2 本を横に並べてつなぐ　仮：二筋を、ねじった棒2本を横に並べてつなぐ読み方で描いた。ねじる回数は2回と仮に決めた。
- forge_thin（工程 9）叩いて厚みを 1/3 に（長さの向きにのばす）　仮：厚みを3分の1にすると仮に決めた。
- grind（工程 11）表を削る（厚みの 25%）　仮：厚みの0.25ほど削ると仮に決めた。
- color（工程 12）色を出す：酸などで地を出す
表せないこと：小刀の形に整えること、焼き入れや冷まし方、沸かす熱の高さとぼやけ方、砥石による面の仕上がりは描けません。「返す」と「二筋に捩じる」は読み方のうちの一つだけで描いています。
