# 鋳むら捩り（imura）
考えた手順（Claude には渡さない）：混ぜきらずに鋳た塊 → 2 本の棒でねじる → のばす → 四角に切り回す → 削る → 酸で地を出す

## 案 1（51 秒）
銀に赤銅を少し入れて混ぜきらずに鋳た塊を、捩じって叩きのばし、四角に切って一つおきに回してつなぎ、酸で色の差を出す、という流れが考えられる案です。捩じり方、「卸す」の意味、熱や液の加減はまだ分かっておらず、試して確かめる必要があります。
1. 地金を用意する
   銀に赤銅を少しだけ足す。材料の覚え書きに「銀に赤銅を少し入れ」とあるので、そう考えられる。白い地は銀、黒い線は赤銅の多い所かもしれない。
   分からない：赤銅をどれだけ入れるかは分からない。試して決める。黒い線が赤銅から出るのかも、まだ推し量り。
2. よく混ぜずに鋳る
   溶かしたあと、かき混ぜきらずに型に流し、塊を作る。材料の覚え書きに「よく混ぜずに鋳る」とあり、板を重ねたものではないとあるので、材料の中のむらで模様を出す技と考えられる。
   分からない：どうやって混ざりきらないようにするか（溶かす順、熱の加減、流すまでの時間）は分からない。試して決める。
3. 二筋にして捩じる
   鋳た塊を二本の棒のようにして、捩じり合わせる、あるいは塊を捩じって二筋にすると読める。覚え書きに「二筋に捩じり」とある。捩じることで、中のむらが渦のように引きのばされるのかもしれない。
   分からない：二本を捩じり合わせるのか、一本を捩じるのか、読み方が分からない。熱いうちか冷えてからかも分からない。
4. 焼きなましながら打ち延べる
   捩じった物を叩いて板にのばす。覚え書きに「打ち延べ」とある。この工房では、叩いてのばすと中のむらが平たく薄くなると判断しており、それが細いひびのような線になるのかもしれない。硬くなったら焼きなまし、この工房の木目金の決まりのように、ゆっくり冷ますのがよいかもしれない。
   分からない：どの厚さまでのばすか、焼きなましの熱と回数は分からない。試して決める。
5. 碁盤の目に切る
   のばした板を四角に切り分ける。覚え書きに「碁盤に切りて」とあり、小箱の表で網の目が四角ごとに向きを変えて見えることと合う。
   分からない：四角の大きさと数は分からない。小箱の表の見た目に合わせて試して決める。
6. 一つおきに向きを回す
   切った四角を、一つおきに回して並べ直す。覚え書きに「一つおきに回し」とあり、小箱の表で四角ごとに線の向きが変わることの元と考えられる。
   分からない：どれだけ回すか（向きを横にするのか、裏返すのか）は分からない。
7. 沸かして一枚につなぐ
   並べた四角を熱して、くっつけて一枚の板にすると考えられる。覚え書きに「沸かし」とある。この工房では、熱しすぎると模様がぼやけたり消えたりすると判断しているので、切れ端で試してから本番に入るのがよいかもしれない。
   分からない：何度まで熱するか、四角をどう押さえて固めるか、つなぐ助けになる物を使うかは分からない。試して決める。
8. 卸す
   覚え書きに「卸して」とある。火から下ろすことかもしれないし、表をけずって平らにならすことかもしれない。小箱の表はさわると平らなので、表をならす意味もありうる。この工房では、表がどの深さで切ったかで模様が決まると判断している。
   分からない：「卸す」が何をさすのか分からない。けずるなら、どれだけけずるかも分からない。
9. 酸に浸して色の差を出す
   板を酸に浸して、白い地と黒い線の色の差を出すと考えられる。覚え書きに「酸に浸す」とある。この工房では、材料のちがいは磨くだけでは見えにくく、液で色の差にして見せると判断しており、どの液でどれだけつけるかは切れ端で試して決めるとしている。
   分からない：どの酸か、濃さ、つける時間は分からない。煮色のような、ほかの色出しでも同じ見た目になるかも分からない。

### 模様の見込み（45 秒）：描く
板を重ねず、混ぜきらずに鋳た塊の中のむらから模様を出す技なので、鋳た塊（ingot）から始めて、捩じる・のばす・四角に切って回す・つなぐ・削る・酸の順に置きかえました。
銀の白い地に、赤銅の多い所が細くのびた黒い網のような線になり、四角ごとに線の向きが変わる、市松のような模様になりそうです。むらの形は説にもとづく仮の見込みです。
- ingot（工程 2）赤銅・銀の、1 つの鋳た塊（中のむら：赤銅の網目。幅の中に 12）　仮：網目は赤銅、地は銀と仮に決めた。網目の数は絵のために仮に 12 とした
- twist（工程 3）ねじる（3 回）。2 本を横に並べてつなぐ　仮：二本を捩じり合わせる読み方を仮に選んだ。捩じる回数は仮に 3 回
- forge_thin（工程 4）叩いて厚みを 1/6 に（縦横に広げる）　仮：厚みを 6 分の 1 にすると仮に決めた。焼きなましは絵では表せないので入れていない
- rearrange（工程 6）切って並べかえる：四角に切って 1 つおきに回す　仮：切る数は仮に 4。回す向きは分からないので、計算のきまった回し方で描く
- bond（工程 7）熱してつなぐ（よくつながる）　仮：よくつながると仮に決めた
- grind（工程 8）表を削る（厚みの 10%）　仮：卸すの意味は分からないので、削る読み方を仮に選んだ。深さは浅く 0.1 と仮に決めた
- color（工程 9）色を出す：酸などで地を出す
表せないこと：むらの本当の形と量、混ぜきらない鋳方、焼きなましとゆっくり冷ますこと、沸かす熱の加減と熱しすぎて模様がぼやけること、四角の本当の回し方（横にするか裏返すか）、酸の種類と色の深さ、小箱の形
計算の知らせ：鋳た塊の中のむらは、「混じり物が結晶の枝のすき間に集まり、叩いてのばすと平たい帯になる」という説の形を、3 次元の網目として仮に描きました（幅の中に網目 12・仮）。網目の本当の形・量・並び方は分かっていません。
