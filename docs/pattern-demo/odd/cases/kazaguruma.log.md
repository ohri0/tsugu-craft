# 風車石畳（kazaguruma）
考えた手順（Claude には渡さない）：3 色を重ねる → 3 本の棒でねじって並べる → 平らにする → 四角に切り 1 つおきに回す → 削る

## 案 1（46 秒）
古い職人の帳面の書き方にそって、赤銅・銀・銅を重ね、三本に捩じって並べてつなぎ、平らにして碁盤に切り、一つおきに回してまたつなぎ、煮色で色を出す、という順の案です。羽の形がどうして出るか、回す量、「卸す」の意味はまだ分かっていないので、試して確かめるための案として見てください。
1. 三つの地金を重ねる
   赤銅・銀・銅の板を重ねる。古い帳面の書き出しが「赤銅・銀・銅を重ね」なので、そこから考えた。箱の蓋の赤・黒・白の羽は、この三つの地金の色かもしれない。
   分からない：重ねる順番、それぞれの厚さ、何枚重ねるかは分からない。試して決める。
2. 重ねた板を一度つなぐ
   捩じる前に、重ねた板が一つにつながっていないと、捩じったときにはがれるかもしれない。古い帳面には捩じる前に沸かすとははっきり書いていないので、推し量りである。この工房の木目金の決まりでは、熱しすぎると模様がぼやけるので切れ端で試すとしている。この技でも同じかもしれない。
   分からない：この工程が本当にあったかは分からない。何度まで熱するか、どう押さえるかも分からない。試して決める。
3. 三本の棒にして捩じる
   古い帳面の「三筋に捩じりて」から、重ねた地金を細長い棒にし、三本それぞれを捩じると考えられる。捩じると層がらせんになり、それが羽の形のもとになるかもしれない。
   分からない：棒の太さ、捩じる回数、三本とも同じ向きに捩じるか、向きを変えるかは分からない。一本の太い棒を捩じって三つに分けるのかもしれない。
4. 三本を並べて沸かしつける
   古い帳面の「並べ沸かし」から、捩じった三本を横に並べ、熱して一つの塊につなぐと考えられる。熱しすぎると層がまざって模様がぼやけるかもしれない、とこの工房では見ている。
   分からない：並べ方（ぴったり付けるか、何かで縛るか）、温度、時間は分からない。
5. 打って平らにのばす
   古い帳面の「打ち平め」から、塊を叩いて板にすると考えられる。この工房の木目金の決まりでは、叩くと中の層は平たく薄くなり、表の模様は表がどの深さで切るかで決まる、としている。途中で焼きなましたら、ゆっくり冷ますのがこの工房の決まりで、この技でもそうしたほうが曲がりにくいかもしれない。
   分からない：どの厚さまでのばすか、何回焼きなますかは分からない。
6. 碁盤の目に切る
   古い帳面の「碁盤に切りて」と、箱の蓋の小さな四角が石畳のように並ぶ様子から、板を同じ大きさの四角に切り分けると考えられる。
   分からない：四角の大きさ、一つの四角に羽が一組入るように切る位置は分からない。
7. 一つおきに向きを回す
   古い帳面の「一つおきに回し」と、箱の蓋でとなりの四角と羽の向きがずれていることから、切った四角を一つおきに回して並べ直すと考えられる。
   分からない：どれだけ回すか（四分の一回りか、半回りか、裏返すのか）は分からない。
8. もう一度沸かしてつなぐ
   古い帳面の「また沸かして」から、並べ直した四角を熱してまた一枚につなぐと考えられる。四角がずれないように押さえる方法は手がかりにない。
   分からない：四角の押さえ方、温度、時間は分からない。
9. 卸す
   古い帳面に「卸す」とある。叩いてさらに薄くのばすことか、表を削って模様を出すことか、どちらとも取れる。意味が分からないので推し量りにとどめる。
   分からない：「卸す」が何をすることか分からない。
10. 煮色で色を出す
   古い帳面の終わりに「煮色」とある。この工房の木目金の決まりでは、材料ごとの色の変わり方のちがいで模様を見せ、液とつける長さは見本の切れ端で決める、としている。赤銅が黒、銅が赤、銀が白に見えれば、箱の蓋の三つの色に合うかもしれない。
   分からない：煮色の液の中身、煮る時間、前の下ごしらえは分からない。地金ごとに何色になるかも試して確かめる。

### 模様の見込み（18 秒）：描く
赤銅・銀・銅を重ねて捩じり、三本を並べてつなぎ、四角に切って回す技です。重ねた層の模様の計算に置きかえました。
捩じれた三本の縞が並び、碁盤の四角ごとに向きがずれて、黒・白・赤の筋が石畳のように並ぶ見込みです。羽の形になるかどうかは、この絵では確かではありません。
- stack（工程 1）赤銅・銀・銅を 9 枚、順に重ねる　仮：順は帳面の書き出しの順で、上から赤銅・銀・銅としました。三つを三回くり返して9枚、厚さは同じにしました。絵のための仮の値です。
- bond（工程 2）熱してつなぐ（よくつながる）　仮：よくつながったとして描きました。
- twist（工程 3）ねじる（2 回）。3 本を横に並べてつなぐ　仮：捩じる回数は2回、三本とも同じ向きとしました。絵のための仮の値です。
- bond（工程 4）熱してつなぐ（よくつながる）　仮：よくつながったとして描きました。
- flatten（工程 5）叩いて平らにする
- rearrange（工程 6）切って並べかえる：四角に切って 1 つおきに回す　仮：縦横3つずつに切るとしました。回す量はこの計算では決められず、四角を回した形で描かれます。
- bond（工程 8）熱してつなぐ（ところどころつながらない）　仮：押さえ方が分からないので、ところどころつながらないかもしれないとしました。
- grind（工程 9）表を削る（厚みの 15%）　仮：表を厚みの0.15だけ浅く削るとしました。叩いてのばす意味かもしれません。
- color（工程 10）色を出す：薬で色を出す（煮色のように）
表せないこと：四角をどれだけ回すか（四分の一回り・半回り・裏返し）の違い、熱の具合、煮色の本当の色あい、羽の形がどう出るかの本当のしくみは表せません。
