# よくある問いと答え（審査・発表のための下書き）

作者が答えるときの下書き。数字は出典か作者の言葉だけ。まだ数字のない所は「（作者に確かめる）」と書いておく。

## 仕様書や作業手順書と、何が違うの？

- 仕様書は「この一つの物」の答え。継ぐの帳面は「なぜそうするか」という職人の判断を、形を確かめる決まり（どの値を・どの範囲で・なぜ・誰の言葉か）として持つ。
- だから、違う石・違う大きさ・違う工房の物にも、その場で当てて確かめられる。石が大きくなれば爪も変わる（石の大きさのつまみ）。
- 仕様書は読まれないと効かない。継ぐは、設計したその場で効き、外れた所が赤くなり、直し方と「誰のどの決まりか」が出る。
- 書いた人がいなくなっても、理由と職人の言葉そのままに戻れる（学ぶ人の「なぜ？」）。

## 形のデータがあれば、十分では？

- 形のデータに残るのは形だけ。なぜその形か（爪の太さの理由など）と、どう作るか（工程・道具・手の決まり）は残らない。
- 20 年たつと、人も道具も材料も変わる。形だけでは、何かが変わったときに直せない。継ぐは形と一緒に、判断と作り方を残す。

## ボタンで直すのと「Claude で直す」は、何が違うの？

- **ボタン**（1 つずつ・まとめて直す）：確かめるルールが出した直し方を、そのまま当てる。プログラムの計算なので、いつも同じ結果で、一瞬で終わる。合言葉も要らない。
- **Claude で直す**：Claude が指輪ぜんたいと帳面を読み、道具（`set_setting`・`set_shank`・`check`・`look`）で直す。直し方が 1 つでないとき（爪を太くするか、本数を増やすか、低くするか）に、見た目への影響や希望の言葉を考えて選び、理由を作業の記録に残す。直したあとは必ず `check` で確かめる。全部戻せる。
- どちらも、寸法と「作れるか」の判断は同じ確かめるルール（帳面の決まり）がする。Claude は選ぶ役で、答えを決める役ではない。

## 誰でも使えるの？

- 石の写真は、白い紙の上で真上から撮り、長辺と深さを測って入れるだけ（測る道具の名前は問わない）。よくある形の石から始めることもできる。
- 作れない所は赤く光り、押せば理由と直し方が出るので、職人でなくても直せる。言葉はやさしい日本語で、専門の言葉には意味を添える（押すとその場で出る）。
- PC でもスマホの縦画面でも動く。公開の版は、はじめに合言葉を入れて開く。自分のパソコンで動かすときは聞かない。
- ただし、最後に作れるかを決めるのは職人。継ぐの数字は目安。

## 職人（作者）がやったことは何？

- **職人の決まり**：爪の最低の太さ（メレ 約 2.5 mm で 0.6 mm、約 8 mm の石で 0.7 mm）、三角の石は角に 1 本ずつの爪 3 本で留まる。目安帳に「職人：石川」として入っている（`ledger/jewelry.json`）。
- **作り方の判断**：石座は 1 つの部品で腕にのせてロウ付けする、ロウですき間を埋めようとせず継ぎ目をぴったり合わせてからつなぐ、石の先が当たる所はザグる、など。
- **直し**：iPhone で触って「分からない」「雑」「不自然」と言った所を、直してもらった（寸法の名前を「石の先〜指」に、正面・横・上を平らな図に、ザグりを丸いくぼみに、ロウのつなぎ目、断面の赤は尖った所だけ、など）。どれも `docs/LOG.md` に日付つきで残っている。
- **決めたこと**：作らないもの（テンションセッティングなど）、外すもの（V 字の爪・絵から組む・石を並べる欄）、出してよい名前。
- 公開の資料の決まり（URL つき）と、出どころのない「仮」の値とは、帳面でも画面でも分けて出している。

## データはどこに残るの？

- **画面**：帳面・作品の記録・手本の動画は、使っている人のブラウザの中（localStorage など）に残る。帳面は印刷できる（魚々子の帳面と、組み立て直すの記録は JSON で書き出せる）。
- **写真**：石の写真の輪郭は、ブラウザの中で読む。サーバーには残さない。
- **Claude**：Claude を使うときだけ、サーバーの関数（`api/claude.ts`）が Claude API に送る。関数は返事をそのまま返すだけで、中身を残さない。API キーは関数だけが持つ。
- **MCP**：Claude のアプリから決まりを足すと、リポジトリの `ledger/jewelry.json` に書き込まれる。コミットすれば「誰がいつ何を変えたか」が git の履歴に残る。

## AI が間違えたら？

- Claude は答えを決めない。帳面の決まりを読んで選び、理由を残す役。寸法と確かめは、プログラムの計算で、いつも同じ答えになる。
- 数字は出典か職人の言葉から。出典のない数字は「仮」と出す。目安で、最後は職人が決める。

## 職人は、暗黙知を出してくれる？

- 話すだけでよい。Claude が決まりの案にし、職人が「これでいい」と決める。職人の名前と言葉そのままが残り、誰の判断かが分かる。
- まだ決まっていない所は、Claude のほうから 1 つずつ聞きに来る。声で答えられる。
- 教えるたびに手を止めなくてよくなる。

## 工房によって答えが違うのでは？

- 違ってよい。帳面は工房ごとに持てる。同じ指輪を、帳面ごとに比べられる。

## 伝統工芸に、どう広げる？

- まずは確かめやすい石留めから。決まりの形（値・範囲・理由・出どころ）は技法によらないので、ほかの技にも広げられる。いまも、覆輪留め・ミル打ち・槌目・鏨彫り・布目象嵌・木目金の帳面がある。
- 作り方が途切れた技は、残った手がかりから組み立て直して答え合わせする（木目金で 11 工程のうち 9）。
- こうした品を作る工房で、標準の受け継ぎのしくみとして使ってもらう。

## どれくらい効果があるの？

- 作り手の数：国が指定した伝統的工芸品の従業員は、約 11.5 万人 → 約 4.8 万人（24 年で約 6 割減。経済産業省の説明資料）。
- （作者に確かめる）デザインと設計の往復の回数と日数、学校で聞く順番を待つ時間（作者の経験では、長いときは 1 時間）。
